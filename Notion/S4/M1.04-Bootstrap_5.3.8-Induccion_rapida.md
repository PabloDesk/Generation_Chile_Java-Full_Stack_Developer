# Bootstrap 5.3.8 - Inducción rápida

## 🎯 Objetivo

Al terminar esta guía deberías poder:

- Entender qué es Bootstrap
- Integrarlo en HTML
- Usar sus componentes más comunes
- Construir una interfaz simple y moderna

---

## 🧠 ¿Qué es Bootstrap?

Es un **framework frontend (HTML + CSS + JS)** que te permite crear interfaces:

- rápidas ⚡
- responsivas 📱
- ordenadas 🎯

👉 En vez de diseñar todo desde cero, usas clases listas.

---

## 📦 Cómo usar Bootstrap

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
```

---

## 🧱 Concepto clave

Bootstrap funciona así:

```
base + modificador
```

```html
<button class="btn btn-primary">Guardar</button>
```

- `btn` → base
- `btn-primary` → estilo

---

## 🏗️ Estructura básica

### 📦 Container

```
<div class="container">Contenido</div>
```

### 📐 Grid (columnas)

```html
<div class="row">
  <div class="col-md-6">1</div>
  <div class="col-md-6">2</div>
</div>
```

### 🛠️ Utilities (atajos)

```html
<p class="text-center mt-4 fw-bold">Texto</p>
```

---

# 🧩 Componentes más importantes

---

## 🔘 Buttons

```html
<button class="btn btn-primary">Primario</button>
<button class="btn btn-success">Aceptar</button>
<button class="btn btn-danger">Eliminar</button>
```

---

## 🚨 Alerts

```html
<div class="alert alert-success">
  Todo salió bien
</div>
```

---

## 🃏 Cards

```html
<div class="card p-3">
  <h5>Título</h5>
  <p>Contenido</p>
  <button class="btn btn-primary">Acción</button>
</div>
```

---

## 🧭 Navbar

```html
<nav class="navbar bg-body-tertiary">
  <div class="container">
    <a class="navbar-brand">Mi App</a>
  </div>
</nav>
```

---

## 📝 Forms

```html
<input class="form-control" placeholder="Correo">
<button class="btn btn-primary mt-2">Enviar</button>
```

---

## 🪟 Modal (interactivo)

```html
<button data-bs-toggle="modal" data-bs-target="#m">Abrir</button>
```

---

## 📂 Accordion

```html
<div class="accordion">
  <div class="accordion-item">
    <button class="accordion-button">Pregunta</button>
  </div>
</div>
```

---

## 📊 Progress

```html
<div class="progress">
  <div class="progress-bar" style="width: 70%">70%</div>
</div>
```

---
