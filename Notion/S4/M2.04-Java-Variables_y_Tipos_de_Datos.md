# Java - Variables y Tipos de Datos

## 🏁 **1. ¿Qué es una Variable en Java?** (Java 21 & 25 LTS)

> Una variable es un espacio reservado en memoria para almacenar un valor.
> 
> Cada variable tiene **un nombre**, **un tipo de dato** y **un valor**.


En Java, **todas** las variables deben tener un tipo definido antes de usarse (**lenguaje fuertemente tipado**).

---

## 📌 **2. Reglas para nombrar variables (Java Naming)**

- Deben **empezar con letra** o con `_` o `$`.
- No deben comenzar con un número.
- No pueden contener espacios.
- **lowerCamelCase** es la convención oficial.
- No usar palabras reservadas del lenguaje.

✔ Correcto:

`int studentAge;`

❌ Incorrecto:

`int 1edad;`

# 🔥 **3. Tipos de Datos en Java**

Java trabaja con 2 grandes categorías:

---

## **A) Tipos Primitivos (8 en total)**

### 📌 Tabla Completa (Java 21/25)

| Tipo | Tamaño | Rango | Ejemplo |
| --- | --- | --- | --- |
| **byte** | 1 byte | -128 a 127 | `byte b = 10;` |
| **short** | 2 bytes | -32,768 a 32,767 | `short s = 20;` |
| **int** | 4 bytes | -2,147,483,648 a 2,147,483,647 | `int n = 100;` |
| **long** | 8 bytes | muy grande | `long l = 10L;` |
| **float** | 4 bytes | decimal simple | `float f = 10.5f;` |
| **double** | 8 bytes | decimal doble precisión | `double d = 99.99;` |
| **boolean** | 1 bit | true/false | `boolean on = true;` |
| **char** | 2 bytes | un carácter Unicode | `char c = 'A';` |

---

## **B) Tipos por Referencia**

Incluye:

- **String**
- **Arrays**
- **Clases (Objetos)**
- **Interfaces**
- **Records (Java 16+)**
- **Enums**

Ejemplo:

```java
String name = "Hackerman";
int[] numbers = {1, 2, 3};
```

---

# 🌟 **4. String: el tipo más usado**

`String` **no es primitivo**, es una clase.

Características:

- Inmutable (no se puede cambiar su valor una vez creado).
- Java optimiza Strings usando el **String Pool**.
- Desde Java 21 se puede usar **Text Blocks**:

```java
String html = """
    <html>
        <body>Hello!</body>
    </html>
""";
```

# ⚙️ **5. Declaración, Inicialización y Asignación**

### Declaración

```java
int edad;
```

### Inicialización

```java
edad = 25;
```

### Declaración + inicialización

```java
int edad = 25;
```

---

# 🧮 **6. Inferencia de Tipos con `var` (Java 10+ LTS)**

Java permite inferir el tipo automáticamente:

```java
var nombre = "Hackerman"; // infiere String
var edad = 30; // infiere int
```

⚠ **No es dinámico**. El tipo queda fijo en compilación.

### No permitido:

```java
var x; // ❌ Debe inicializarse
```

---

# 🧱 **7. Constantes: `final`**

Variables cuyo valor NO puede cambiar.

```java
final double PI = 3.1416;
```

Convención: **UPPER_SNAKE_CASE**

---

# 🔄 **8. Conversión de Tipos (Casting)**

### ✔ Implícito

```java
int n = 10;
double d = n; // OK
```

### ✔ Explícito

```java
double precio = 9.99;
int entero = (int) precio; // 9
```

# 🆚 **9. Primitivos vs Wrappers**

Java tiene clases que envuelven cada primitivo:

| Primitivo | Wrapper |
| --- | --- |
| int | Integer |
| double | Double |
| boolean | Boolean |
| char | Character |

Se usan para:

- Collections (`List<Integer>`)
- Operaciones null-safe
- Métodos utilitarios

Ejemplo:

```java
Integer n = 10;
```

# 🧩 **10. Novedades Relevantes en Java 21 y Java 25**

Aunque variables y tipos no cambian mucho, sí cambian **cómo trabajamos con ellos**:

---

## ✔ Pattern Matching (Java 21 LTS)

Permite verificar tipos de forma más elegante:

```java
Object data = "Hola";

if (data instanceof String s) {
    System.out.println(s.toUpperCase());
}
```

---

## ✔ Records (desde Java 16, estables en Java 21 y 25)

Representan datos inmutables:

```java
public record User(String name, int age) {
}
```

---

## ✔ `switch` Mejorado

Java 21 trae `switch` más expressivo:

```java
String role = "ADMIN";

String msg = switch (role) {
    case "ADMIN" -> "Acceso total";
    case "USER" -> "Acceso limitado";
    default -> "Desconocido";
};
```

# 🖥️ **11. Ejemplos Completos**

### Ejemplo 1 — Uso general de variables

```java
public class Main {
    public static void main(String[] args) {
        int age = 21;
        double salary = 999.99;
        boolean active = true;
        char grade = 'A';
        String name = "Hackerman";

        System.out.println(name + " tiene " + age + " años.");
    }
}

```

---

### Ejemplo 2 — Inferencia y Casting

```java
public class Main {
    public static void main(String[] args) {
        var price = 19.99; // double
        int rounded = (int) price;

        System.out.println("Redondeado: " + rounded);
    }
}

```

---

# 🧠 **12. Errores Comunes**

⚠ Declarar sin inicializar:

```java
int x;
System.out.println(x); // ❌ Error

```

⚠ No usar sufijo en long o float:

```java
long big = 10; // OK
long big2 = 10L; // recomendado
```

⚠ Confundir `char` con `String`:

```java
char c = "A"; // ❌
char c = 'A'; // ✔
```

---

# 📚 **13. Buenas Prácticas**

✔ Usar nombres descriptivos:

`int userAge`, no `int a`.

✔ Preferir `var` donde el tipo es obvio.

✔ Usar `final` para constantes.

✔ Evitar tipos más grandes de lo necesario.

✔ Usar wrappers solo cuando sea necesario.

# VariablesDemo.java

```java
public class VariablesDemo {

    public static void main(String[] args) {

        System.out.println("=== DEMO VARIABLES EN JAVA ===");

        // ========================
        // 🔢 ENTEROS
        // ========================
        System.out.println("\n--- TIPOS ENTEROS ---");

        byte b = 127;
        short s = 32000;
        int i = 100000;
        long l = 10000000000L;

        System.out.println("byte (8 bits): " + b);
        System.out.println("short (16 bits): " + s);
        System.out.println("int (32 bits): " + i);
        System.out.println("long (64 bits): " + l);

        System.out.println("👉 Todos representan números enteros");

        // ========================
        // 🔢 DECIMALES
        // ========================
        System.out.println("\n--- TIPOS DECIMALES ---");

        float f = 3.14f;
        double d = 3.1415926535;

        System.out.println("float (32 bits): " + f);
        System.out.println("double (64 bits): " + d);

        System.out.println("👉 double es más preciso que float");

        // ========================
        // 🔤 CHAR
        // ========================
        System.out.println("\n--- TIPO CHAR ---");

        char letra = 'A';

        System.out.println("char: " + letra);
        System.out.println("👉 Representa UN solo carácter");

        // ========================
        // ✅ BOOLEAN
        // ========================
        System.out.println("\n--- TIPO BOOLEAN ---");

        boolean activo = true;

        System.out.println("boolean: " + activo);
        System.out.println("👉 Solo puede ser true o false");

        // ========================
        // 📦 WRAPPER CLASSES
        // ========================
        System.out.println("\n--- WRAPPER CLASSES ---");

        Integer wi = 100;
        Double wd = 3.14;
        Character wc = 'A';
        Boolean wb = true;

        System.out.println("Integer: " + wi);
        System.out.println("Double: " + wd);
        System.out.println("Character: " + wc);
        System.out.println("Boolean: " + wb);

        System.out.println("👉 Son versiones OBJETO de los tipos primitivos");

        // ========================
        // 🔁 AUTOBOXING
        // ========================
        System.out.println("\n--- AUTOBOXING ---");

        int numero = 10;
        Integer numeroObjeto = numero; // conversión automática

        System.out.println("int: " + numero);
        System.out.println("Integer (desde int): " + numeroObjeto);

        System.out.println("👉 Java convierte automáticamente (autoboxing)");

        // ========================
        // 🔄 UNBOXING
        // ========================
        System.out.println("\n--- UNBOXING ---");

        Integer numObj = 20;
        int numPrim = numObj;

        System.out.println("Integer: " + numObj);
        System.out.println("int (desde Integer): " + numPrim);

        System.out.println("👉 También convierte de objeto a primitivo");

        // ========================
        // 🎯 COMPARACIÓN
        // ========================
        System.out.println("\n--- DIFERENCIA CLAVE ---");

        int x = 10;
        Integer y = 10;

        System.out.println("int x = " + x);
        System.out.println("Integer y = " + y);

        System.out.println("👉 int = valor simple");
        System.out.println("👉 Integer = objeto con métodos");

        System.out.println("\n=== FIN DEMO ===");
    }
}
```
