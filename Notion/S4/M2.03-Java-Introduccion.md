# Java - Introducción

# 💻 **¿Qué es Java?**

Java es un lenguaje de programación **orientado a objetos** y **basado en clases**, diseñado para ser **seguro**, **portable**, **robusto** y con el mínimo de dependencias entre plataformas.

Fue lanzado en **1995**, y casi tres décadas después **sigue siendo uno de los lenguajes más utilizados del mundo**, especialmente en áreas donde la estabilidad y la escalabilidad son fundamentales.

Java se diseñó desde su origen con un objetivo clave:

> “Write Once, Run Anywhere” (WORA)
> 
> Escribe el código una vez y ejecútalo en cualquier plataforma.
> 

Esto se logra gracias a su arquitectura basada en **bytecode** y la **Máquina Virtual de Java (JVM)**.

# 🕰 **Historia de Java (Resumen Cronológico)**

- **1991** – Comienza como “Project Green”, creado por James Gosling.
- **1995** – Se publica Java 1.0 con el enfoque en aplicaciones web.
- **1998** – Nace Java 2.
- **2006** – Sun libera Java como software libre (OpenJDK).
- **2010** – Oracle compra Sun Microsystems y toma control del lenguaje.
- **2018 en adelante** – Se adopta un ciclo de lanzamientos cada 6 meses.
- **Hoy** – Java 21 es la versión LTS más moderna.

# 🌟 **Características clave de Java**

---

## 🔁 **Independencia de Plataforma**

Java no se ejecuta directamente en el sistema operativo.

Se ejecuta en la **JVM**, lo que permite que el mismo archivo `.class` funcione en cualquier sistema.

---

## 🚚 **Portabilidad (WORA)**

Java utiliza bytecode, un formato intermedio que la JVM interpreta.

Por eso un programa escrito en Windows funciona en Linux o Mac sin cambios.

---

## 🧱 **Robustez**

Java ofrece:

- Manejo de excepciones
- Recolección automática de basura
- Tipado fuerte
- Seguridad integrada
- Compatibilidad hacia atrás

---

## 🔐 **Seguridad**

Java incorpora mecanismos como:

- Sandbox
- Verificación de bytecode
- APIs criptográficas
- Firmas digitales
- Manejo seguro de memoria

Esto lo hace especialmente preferido por bancos y sistemas críticos.

---

# 🧠 **Arquitectura Interna de Java (JDK, JRE y JVM)**

Esta es una de las explicaciones más importantes.

---

## 🔧 **JDK — Java Development Kit**

Es el kit de desarrollo completo de Java:

Incluye:

- **Compilador (`javac`)**
- **JVM**
- **JRE**
- Herramientas para debugging
- Librerías base
- Documentación

Necesario para **desarrollar** aplicaciones Java.

---

## 🚀 **JRE — Java Runtime Environment**

Incluye:

- JVM
- Librerías del core

Sirve únicamente para **ejecutar** Java, no para desarrollarlo.

---

## ⚙️ **JVM — Java Virtual Machine**

La JVM interpreta y ejecuta el bytecode.

Responsable de:

- Manejo de memoria
- Garbage Collector
- Optimizaciones JIT
- Seguridad y sandbox

# 🧱 **Java como Lenguaje Orientado a Objetos**

Java nació con el paradigma OOP en su ADN.

### Conceptos base:

- **Clase:** plano o molde
- **Objeto:** instancia de una clase
- **Atributos:** características
- **Métodos:** comportamientos
- **Herencia:** reutilización
- **Polimorfismo:** comportamientos distintos
- **Abstracción:** simplificar lo complejo
- **Encapsulación:** proteger los datos

Estos conceptos serán la base de todo el Bootcamp.

# 🔢 **Versiones Modernas de Java (muy importante)**

Java publica versiones cada 6 meses, pero solo algunas reciben soporte prolongado (**LTS – Long Term Support**).

Según lo confirmado por Oracle y OpenJDK, **Java 25** es efectivamente una versión **LTS** lanzada el **16 de septiembre de 2025**.

| Versión | Tipo | Estado | Uso en empresas |
| --- | --- | --- | --- |
| **8** | LTS | Antiguo | Mucho legado (aún presente en banca y sistemas críticos) |
| **11** | LTS | Estable | Muy común en producción |
| **17** | LTS | Recomendado | Amplio y maduro |
| **21** | LTS | Actual ampliamente adoptado (2023–2025) | ✔ ✔ ✔ |
| **25** | **LTS** | **Nueva versión LTS (desde sept. 2025)** | Empezará adopción progresiva |
