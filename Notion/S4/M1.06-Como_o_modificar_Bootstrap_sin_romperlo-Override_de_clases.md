# Cómo modificar Bootstrap sin romperlo (Override de clases)

## 🧠 Objetivo

- Entender cómo funciona Bootstrap internamente.
- Aprender a sobrescribir estilos correctamente.
- Evitar errores comunes al modificar componentes.
- Aplicar cambios sin romper el diseño base.

---

## ⚙️ 1. Cómo funciona Bootstrap realmente

👉 Bootstrap es solo **CSS + clases predefinidas**.

Ejemplo:

```html
<button class="btn btn-primary">Click</button>
```

Bootstrap ya tiene algo como:

```css
.btn {
  padding: 8px 16px;
  border-radius: 6px;
}

.btn-primary {
  background-color: blue;
  color: white;
}
```

<aside>
💡

> 💬 “Cuando usas Bootstrap, estás aceptando sus reglas… pero puedes modificarlas.”
> 
</aside>

---

## 🧨 2. El error más común

❌ Hacer esto:

```css
button {
  background-color: red;
}
```

👉 Problema:

- Afecta TODOS los botones
- Rompe Bootstrap
- No es específico

---

## ✅ 3. Forma correcta: Override con clases

✔ Siempre usa clases más específicas

```css
.btn-primary {
  background-color: red;
}
```

👉 Esto reemplaza el azul de Bootstrap

<aside>
💡

> 💬 “No luches contra Bootstrap… habla su mismo idioma”
> 
</aside>

---

## 🧱 4. Estrategia correcta (orden IMPORTANTE)

### ✔ Paso 1: Importar Bootstrap

```html
<link href="bootstrap.css" rel="stylesheet">
```

### ✔ Paso 2: Tu CSS DESPUÉS

```html
<link href="styles.css" rel="stylesheet">
```

👉 CSS se lee de arriba hacia abajo

👉 El último gana

<aside>
💡

> 💬 “El orden también es jerarquía”
> 
</aside>

---

## 🧬 5. Aumentar especificidad (sin !important)

### ❌ Mal

```css
.btn {
  background: red;
}
```

### ✔ Bien

```css
button.btn-primary {
  background: red;
}
```

O mejor aún:

```css
.mi-boton.btn-primary {
  background: red;
}
```

👉 Combinas clases = más específico

---

## 🧠 6. Crear tu propia clase (MEJOR PRÁCTICA)

```html
<button class="btn btn-primary mi-boton">Click</button>
```

```css
.mi-boton {
  background-color: red;
}
```

✔ No rompes Bootstrap

✔ Puedes reutilizar

✔ Control total

<aside>
💡

> 💬 “Bootstrap te da la base… tú personalizas encima”
> 
</aside>

---

## ⚠️ 7. ¿Cuándo usar `!important`?

```css
color: red !important;
```

👉 Solo cuando:

- No puedes sobrescribir de otra forma
- Es un caso puntual

❌ NO usar siempre

❌ NO como solución fácil

<aside>
💡

> 💬 “!important es el botón nuclear”
> 
</aside>

---

## 🔍 8. Caso real paso a paso

### HTML:

```html
<button class="btn btn-primary">Guardar</button>
```

### Quiero:

👉 Cambiar color a verde oscuro

---

### ✔ Opción 1 (override directo)

```css
.btn-primary {
  background-color: darkgreen;
}
```

---

### ✔ Opción 2 (mejor práctica)

```html
<button class="btn btn-primary btn-custom">Guardar</button>
```

```css
.btn-custom {
  background-color: darkgreen;
}
```
