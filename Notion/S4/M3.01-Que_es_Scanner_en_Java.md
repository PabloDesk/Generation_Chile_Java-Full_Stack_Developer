# 🔍 Qué es Scanner en Java

`Scanner` es una clase de Java que permite **leer datos ingresados por el usuario** desde el teclado.

Forma parte del paquete:

```java
import java.util.Scanner;
```

> Piensa en Scanner como un “micrófono” del programa: permite que el usuario hable con el programa y este reciba esa información.


Se usa cuando queremos que el usuario **ingrese texto, números, decisiones, etc.**

---

# 🎯 **¿Para qué lo usamos?**

✔ Leer información escrita por el usuario

✔ Crear programas interactivos

✔ Pedir edades, nombres, números, opciones de menú

✔ Evitar valores fijos en el código

---

# 📝 **Cómo se usa Scanner (estructura básica)**

```java

public class DemoScanner {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);  // 1) Crear el Scanner

        System.out.print("Ingresa tu nombre: ");
        String nombre = sc.nextLine();        // 2) Leer texto

        System.out.print("Ingresa tu edad: ");
        int edad = sc.nextInt();              // 3) Leer entero

        System.out.println("Hola " + nombre + ", tienes " + edad + " años.");

        sc.close(); // 4) Cerrar el Scanner (buena práctica)
    }
}
```

---

# 🔎 Explicación de los métodos más usados

| Método | ¿Qué lee? |
| --- | --- |
| `nextLine()` | Texto completo (incluye espacios) |
| `nextInt()` | Números enteros |
| `nextDouble()` | Números decimales |
| `nextBoolean()` | true o false |

---

# ⚠️ **Errores comunes**

## ❌ Error 1: No importar Scanner

```java
Scanner sc = new Scanner(System.in); // ERROR si no importas
```

✔ Arreglar:

```java
import java.util.Scanner;
```

---

## ❌ Error 2: Confundir nextLine() con nextInt()

```java
int edad = sc.nextLine(); // ❌ NO funciona, no convierte
```

---

## ❌ Error 3: No cerrar el Scanner

No es un error fatal, pero es **mala práctica**.

✔ Siempre cerrar al final:

```java
sc.close();
```

# 🎮 **Ejemplo más completo**

Simular un pequeño menú interactivo.

```java
import java.util.Scanner;

public class MenuScanner {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.println("=== Menú del Bootcamp ===");
        System.out.println("1. Ver perfil");
        System.out.println("2. Ver progreso");
        System.out.println("3. Salir");
        System.out.print("Elige una opción: ");

        int opcion = sc.nextInt(); // leer número

        if (opcion == 1) {
            System.out.println("Mostrando perfil del usuario...");
        } else if (opcion == 2) {
            System.out.println("Cargando progreso de aprendizaje...");
        } else if (opcion == 3) {
            System.out.println("Saliendo del sistema...");
        } else {
            System.out.println("Opción no válida.");
        }

        sc.close();
    }
}

```

---

> [!NOTE]
> “Aquí el usuario escribe un número que Scanner captura.
>  
> El programa lo interpreta y ejecuta una acción diferente según la opción.
>
> Con Scanner logramos que el programa deje de ser rígido y se vuelva interactivo.”
