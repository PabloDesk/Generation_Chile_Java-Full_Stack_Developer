# Actividad Guiada: “Reconstruyendo una Web con Bootstrap”

## 🎯 Objetivo

- Identificar la estructura semántica de una página web.
- Comprender cómo Bootstrap reemplaza CSS manual.
- Modificar clases Bootstrap con intención (no al azar).
- Reconocer componentes clave: **Navbar, Hero, Carousel y Footer**.

---

# 🧠 1. Concepto base (explicación breve para clase)

Antes de usar Bootstrap:

👉 Nosotros hacíamos esto en CSS:

- `display: flex`
- `margin`, `padding`
- `background-color`
- `text-align`

👉 Bootstrap ya trae todo eso listo en clases como:

- `d-flex`
- `p-3`, `m-2`
- `bg-dark`
- `text-center`

💡 **Idea clave para alumnos:**

> Bootstrap = “CSS ya hecho, reutilizable mediante clases”
> 

---

# 🏗️ 2. Estructura Semántica Base

Primero deben entender la página **SIN Bootstrap**:

```html
<body>

  <header></header>   <!-- Navbar -->

  <main>
    <section></section> <!-- Hero -->
    <section></section> <!-- Carousel -->
  </main>

  <footer></footer>

</body>
```

💬 Tu discurso:

> “Bootstrap no reemplaza HTML, lo potencia. La estructura sigue siendo semántica.”
>

# 🧭 3. Paso 1: Navbar (desde Bootstrap)

!https://www.tutorialrepublic.com/lib/images/bootstrap-5/bootstrap-navbar-color-schemes.png

!https://forum.bootstrapstudio.io/uploads/default/original/2X/f/f09d86098cd159cb671c3b465b186fd0516a2c74.png

!https://i.sstatic.net/PccFK.png

## 🔍 Instrucción

Ir a:

👉 https://getbootstrap.com/docs/5.3/components/navbar/

Copiar un navbar básico.

## 🛠️ Modificaciones guiadas

Que cambien:

```html
<nav class="navbar navbar-expand-lg bg-body-tertiary">
```

### ✏️ Cambios:

- `bg-body-tertiary` → `bg-dark`
- Agregar: `navbar-dark`
- Agregar: `px-4`

### 💡 Explicación:

| Clase | Qué hace | Equivalente CSS |
| --- | --- | --- |
| `bg-dark` | Fondo oscuro | `background-color` |
| `navbar-dark` | Texto claro | `color: white` |
| `px-4` | Padding horizontal | `padding-left/right` |

💬 Refuerzo:

> “No estamos decorando… estamos tomando decisiones visuales”
>

# 🦸 4. Paso 2: Hero Section

!https://mdbootstrap.com/img/Marketing/github/hero/basic1.png

!https://codepen.io/JacobLett/pen/ExPLYEy/image/large.png

!https://getbootstrap.com/docs/5.0/examples/heroes/bootstrap-docs.png

## 🔍 Instrucción

Crear sección manual usando utilidades Bootstrap:

```html
<section class="text-center p-5 bg-light">
  <h1>Bienvenidos</h1>
  <p>Mi primera página con Bootstrap</p>
  <button class="btn btn-primary">Comenzar</button>
</section>
```

## 🛠️ Modificaciones

- `bg-light` → `bg-primary text-white`
- `p-5` → probar `p-3` o `p-5`
- botón: `btn-primary` → `btn-outline-light`

### 💡 Explicación:

| Clase | Qué hace |
| --- | --- |
| `text-center` | Centra contenido |
| `p-5` | Espaciado |
| `btn` | Estilo base botón |
| `btn-primary` | Color |

💬 Refuerzo:

> “Bootstrap funciona como LEGO: piezas pequeñas que juntas crean UI”
>

## 🛠️ Modificaciones

- Cambiar imágenes
- Agregar texto dentro (`carousel-caption`)
- Probar quitar autoplay (`data-bs-ride`)

### 💡 Explicación:

| Elemento | Función |
| --- | --- |
| `carousel` | Contenedor |
| `carousel-item` | Cada slide |
| `active` | Slide inicial |

💬 Refuerzo:

> “Aquí ya entramos a componentes con JS incluido”

# 🧾 6. Paso 4: Footer

!https://d3h2k7ug3o5pb3.cloudfront.net/image/2020-11-27/98c41b80-30a8-11eb-ae9f-09e7aa62c338.jpg

!https://www.codewithfaraz.com/img/bootstrap%20footer%20template%20for%20every%20website%20style.gif

!https://d2gdtie5ivbdow.cloudfront.net/media/images/bootstrap_footers_cover.PNG

## 🔍 Instrucción

Crear footer simple:

```html
<footer class="bg-dark text-white text-center p-3">
  <p>© 2026 Mi Sitio Web</p>
</footer>
```

## 🛠️ Modificaciones

- Cambiar `text-center` → `text-start`
- Agregar `container`
- Agregar links

💬 Refuerzo:

> “El footer también comunica jerarquía y estructura”
>
