# Shorthand en CSS: Escribe menos, entiende más

## 🎯 Objetivo

- Entender qué es shorthand en CSS.
- Aplicarlo correctamente en `margin` y `padding`.
- Leer y escribir código más limpio.
- Prepararse para entender clases de Bootstrap (`p-3`, `m-2`, etc.).

---

## 🧠 1. ¿Qué es Shorthand?

👉 Shorthand = forma abreviada de escribir CSS.

En vez de esto:

```css
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;
```

Usamos:

```css
padding: 10px 20px 10px 20px;
```

## 🔄 2. Regla universal (IMPORTANTE)

Cuando usamos shorthand:

👉 Siempre sigue este orden:

**🕐 Arriba → Derecha → Abajo → Izquierda**

(sentido del reloj)

---

## 🔢 3. Las 4 formas de shorthand

---

### 🟢 1 valor (TODO IGUAL)

```css
padding: 20px;
```

| Arriba | Derecha | Abajo | Izquierda |
| --- | --- | --- | --- |
| 20px | 20px | 20px | 20px |

---

### 🟡 2 valores (vertical / horizontal)

```css
padding: 10px 20px;
```

| Arriba | Derecha | Abajo | Izquierda |
| --- | --- | --- | --- |
| 10px | 20px | 10px | 20px |

👉 Primer valor = arriba/abajo

👉 Segundo valor = derecha/izquierda

---

### 🟠 3 valores

```css
padding: 10px 20px 5px;
```

| Arriba | Derecha | Abajo | Izquierda |
| --- | --- | --- | --- |
| 10px | 20px | 5px | 20px |

👉 Derecha = izquierda

---

### 🔴 4 valores (completo)

```css
padding: 10px 20px 5px 0;
```

| Arriba | Derecha | Abajo | Izquierda |
| --- | --- | --- | --- |
| 10px | 20px | 5px | 0 |

---

## 🧱 4. Aplica igual para margin

```css
margin: 20px;
margin: 10px 30px;
margin: 10px 20px 5px;
margin: 10px 20px 5px 0;
```

## 🧠 5. Cómo pensar shorthand (truco mental)

👉 Pregúntate:

1. ¿Todo igual? → 1 valor
2. ¿Vertical vs horizontal? → 2 valores
3. ¿Arriba distinto? → 3 valores
4. ¿Todo distinto? → 4 valores

---

## ⚠️ 6. Errores comunes

❌ Pensar que el orden es izquierda a derecha

❌ Olvidar que derecha = izquierda en 2 y 3 valores

❌ Usar demasiados valores innecesarios

---

## 🔗 7. Conexión con Bootstrap

Bootstrap usa shorthand en forma de clases:

| Clase | Equivalente CSS |
| --- | --- |
| `p-3` | padding: valor uniforme |
| `px-3` | padding izquierda/derecha |
| `py-2` | padding arriba/abajo |
| `mt-4` | margin-top |
| `mb-2` | margin-bottom |

Ejemplo:

```html
<div class="p-3 px-5"></div>
```

👉 Primero aplica `p-3`

👉 Luego `px-5` lo sobreescribe horizontalmente

> 💬 “Bootstrap es shorthand convertido en clases”
>
