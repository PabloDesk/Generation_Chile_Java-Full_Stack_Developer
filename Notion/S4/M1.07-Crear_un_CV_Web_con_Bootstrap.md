# Actividad Individual - Crear un CV Web con Bootstrap

## 🎯 Objetivo de la actividad

Crear un **Currículum Vitae en formato web** de manera **individual**, utilizando **Bootstrap obligatoriamente** y complementándolo con **CSS personalizado** si se desea.

La idea es que cada estudiante construya una página que represente su perfil profesional de forma clara, moderna y visualmente atractiva.

---

## 📌 Condición obligatoria

✅ El trabajo **debe usar Bootstrap sí o sí**

✅ Puede incluir **CSS personalizado** para mejorar diseño, colores, tipografías, efectos o estilo general

❌ No se permite hacer el CV solo con HTML y CSS sin Bootstrap

---

## 🧠 Propósito de esta actividad

Con esta actividad se busca que el estudiante practique:

- estructura de una página web real
- uso de componentes de Bootstrap
- organización visual de información
- personalización de estilos
- presentación profesional de su perfil

---

# 📝 Instrucciones de la actividad

## 1) Crear el proyecto

Cada estudiante deberá crear una carpeta de trabajo con al menos estos archivos:

```
cv-bootstrap/
│── index.html
│── style.css
```

---

## 2) Integrar Bootstrap

El archivo `index.html` debe incluir Bootstrap 5.3.8 mediante CDN.

Ejemplo:

```
<linkhref="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"rel="stylesheet">
```

y al final del `body`:

```
<scriptsrc="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
```

---

## 3) Crear un CV web personal

Cada estudiante debe construir una página tipo CV o portafolio personal.

Puede estar basada en sí mismo o en un perfil ficticio profesional si aún no tiene experiencia laboral.

---

# 🧩 Estructura mínima obligatoria

El CV debe incluir como mínimo las siguientes secciones:

## 1. Encabezado o presentación

Debe incluir:

- nombre completo
- rol o área de interés
- breve descripción o presentación
- foto opcional

Ejemplo:

- “Hackerman”
- “Desarrollador Full Stack Jr”
- “Apasionado por la tecnología y el aprendizaje constante”

---

## 2. Sobre mí

Un pequeño texto donde explique:

- quién es
- qué está estudiando
- qué le interesa del mundo tech
- qué objetivo profesional tiene

---

## 3. Habilidades

Debe mostrar sus habilidades usando Bootstrap de forma visual.

Ejemplo:

- HTML
- CSS
- JavaScript
- Java
- Git
- Trabajo en equipo
- Resolución de problemas

Aquí pueden usar:

- badges
- cards
- listas
- progress bars

---

## 4. Formación o estudios

Debe incluir información como:

- bootcamp actual
- cursos realizados
- enseñanza media
- certificaciones si tiene

---

## 5. Proyectos o experiencia

Si no tiene experiencia laboral, puede agregar:

- proyectos personales
- trabajos académicos
- ejercicios importantes
- portafolio ficticio bien planteado

---

## 6. Contacto

Debe incluir al menos:

- correo
- GitHub
- LinkedIn si tiene
- ciudad o país opcional

---

# 🧱 Requisitos técnicos obligatorios

El CV debe usar **Bootstrap en su estructura o componentes**.

Debe incluir al menos:

- `container`
- sistema de grilla (`row`, `col`)
- al menos **2 componentes de Bootstrap**
- al menos **3 utilidades de Bootstrap**

---

## ✅ Ejemplos de componentes que pueden usar

- Navbar
- Card
- Button
- Badge
- Alert
- Progress
- Modal
- Accordion
- List group

---

## ✅ Ejemplos de utilidades que pueden usar

- `text-center`
- `mt-4`
- `mb-3`
- `py-5`
- `shadow`
- `rounded`
- `d-flex`
- `justify-content-center`
- `bg-dark`
- `text-white`

---

# 🎨 Diseño

Cada estudiante puede personalizar el diseño como quiera.

Puede elegir libremente:

- colores
- tipografías
- distribución
- estilo visual
- modo claro u oscuro
- efectos hover
- sombras
- bordes redondeados

La única condición es que el resultado se vea:

- ordenado
- legible
- profesional
- coherente visualmente

---

# 🚀 Desafío extra

Quien quiera subir el nivel puede agregar:

- foto de perfil
- íconos
- barra de navegación
- sección de proyectos con cards
- botones a redes
- animaciones suaves
- diseño responsive más trabajado
- modo oscuro
- efecto hover en cards o botones

---

# 📋 Entregable

Cada estudiante debe entregar:

- carpeta del proyecto
- archivo `index.html`
- archivo `style.css`
- evidencia de uso de Bootstrap

Si el trabajo se sube a GitHub, debe incluir:

- repositorio ordenado
- README simple
- nombre claro del proyecto

---

# 🛠️ Sugerencia de pasos para trabajar

## Paso 1

Crear el HTML base e integrar Bootstrap.

## Paso 2

Definir la estructura general del CV.

## Paso 3

Agregar contenido real o ficticio profesional.

## Paso 4

Aplicar clases Bootstrap para layout y componentes.

## Paso 5

Agregar CSS personalizado para mejorar el diseño.

## Paso 6

Revisar que se vea bien en escritorio y móvil.

---

# 💡 Recomendaciones

- no recargar la página con demasiados colores
- usar espacios y márgenes correctamente
- mantener una tipografía legible
- destacar lo importante
- no escribir bloques enormes de texto
- hacer que el CV se vea como una presentación profesional real

---

# 🧪 Ejemplo de enfoque posible

Un estudiante puede crear un CV con esta estructura:

- Hero principal con nombre y rol
- Sobre mí en una card
- Habilidades en badges
- Estudios en una lista
- Proyectos en cards
- Contacto con botones

---

# 🏁 Instrucción final

**Debes crear tu CV web de forma individual usando Bootstrap obligatoriamente.**

Puedes apoyarte en CSS personalizado para hacerlo más atractivo, pero Bootstrap debe estar presente en la estructura, componentes y estilos del proyecto.
