# 🎨 **1. Espaciado (Margin & Padding)**

| Clase | Categoría | Significado | Explicación |
| --- | --- | --- | --- |
| `m-0` | Margin | Margin 0 | Quita todo el margen |
| `m-1` a `m-5` | Margin | 0.25rem → 3rem | Espacio externo |
| `mt-3` | Margin Top | Margen arriba | Separar secciones |
| `mb-4` | Margin Bottom | Margen abajo | Espacio entre bloques |
| `ms-3` | Margin Start | Margen izquierda | Para íconos o textos |
| `p-3` | Padding | Espaciado interno | Para tarjetas o secciones |
| `px-4` | Padding X | Padding horizontal | Botones amplios |
| `py-5` | Padding Y | Padding vertical | Hero sections amplias |

# 🧲 **8. Auto-Margins (Mover elementos con margen automático)**

### *Esta sección es la más importante para alinear contenido en navbars y flexbox.*

| Clase | Dirección | Lo que hace | Ideal para |
| --- | --- | --- | --- |
| `ms-auto` | Hacia la derecha | Empuja el elemento al final | Navbars, flexbox |
| `me-auto` | Hacia la izquierda | Empuja al inicio | Grids flex |
| `mx-auto` | Horiz. | Centra elemento | Cards, contenedores |
| `mt-auto` | Abajo | Empuja hacia abajo | Footers flex |
| `mb-auto` | Arriba | Empuja hacia arriba | Layouts verticales |
| `my-auto` | Vertical | Centrado vertical | Contenedores altos |

### Ejemplo navbar:

```html
<ul class="navbar-nav ms-auto">
```
