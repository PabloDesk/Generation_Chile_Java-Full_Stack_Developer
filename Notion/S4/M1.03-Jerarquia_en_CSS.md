# Jerarquía en CSS: ¿Quién manda realmente?

## 🧠 Objetivo

- Entender cómo CSS decide qué estilo aplicar.
- Diferenciar entre `id`, `class`, etiquetas y otros selectores.
- Evitar errores comunes al trabajar con estilos.
- Preparar la base para usar Bootstrap correctamente.

---

## 🧩 1. ¿Qué es la jerarquía en CSS?

👉 CSS no aplica estilos al azar.

Cuando hay **varias reglas para un mismo elemento**, el navegador decide cuál usar según:

1. Especificidad
2. Orden de aparición
3. Importancia (`!important`)

> 💬 “CSS es como una pelea… siempre gana el más específico.”

---

## 🏆 2. Orden de prioridad (de menor a mayor)

| Nivel | Selector | Ejemplo |
| --- | --- | --- |
| 1️⃣ | Etiqueta | `p`, `h1`, `div` |
| 2️⃣ | Clase | `.boton` |
| 3️⃣ | ID | `#header` |
| 4️⃣ | Inline | `style="color:red"` |
| 5️⃣ | `!important` | `color: red !important` |

---

## 🔍 3. Ejemplo práctico

```html
<p id="texto" class="rojo">Hola mundo</p>
```

```css
p {
  color: blue;
}

.rojo {
  color: green;
}

#texto {
  color: red;
}
```

👉 Resultado final: **rojo**

### 📌 ¿Por qué?

Paso a paso:

1. `p` → azul (nivel bajo)
2. `.rojo` → verde (más fuerte)
3. `#texto` → rojo (más específico)

✔ Gana el ID

---

## 🧱 4. Tipos de selectores clave

### 🔹 Etiqueta

```css
p {
  color: blue;
}
```

✔ Aplica a TODOS los `<p>`

---

### 🔹 Clase

```css
.boton {
  background: red;
}
```

✔ Se puede reutilizar muchas veces

---

### 🔹 ID

```css
#header {
  background: black;
}
```

✔ Único por página (no repetir)

---

### 🔹 Combinado

```css
div p {
  color: red;
}
```

✔ Aplica a `<p>` dentro de `<div>`

---

### 🔹 Múltiples clases

```html
<button class="btn btn-primary"></button>
```

> 💬 “Bootstrap usa esto TODO el tiempo”
>

## ⚠️ 5. Errores comunes

❌ Usar muchos `id`

❌ Abusar de `!important`

❌ No entender por qué un estilo no se aplica

❌ Sobrescribir Bootstrap sin saber qué clase es más fuerte

---

## 🧪 6. Mini actividad

Dado este código:

```html
<h1 id="titulo" class="azul">Hola</h1>
```

```css
h1 {
  color: black;
}

.azul {
  color: blue;
}

#titulo {
  color: red;
}
```

### ❓ Preguntas

1. ¿Qué color se aplica?
2. ¿Por qué?
3. ¿Qué pasaría si agrego `!important` a `.azul`?

---

## 🧠 7. Conexión con Bootstrap

Bootstrap usa principalmente:

- `class`
- muchas clases juntas
- baja dependencia de `id`

Ejemplo real:

```html
<button class="btn btn-primary p-3"></button>
```

> 💬 “Bootstrap funciona porque entiende bien la jerarquía”
