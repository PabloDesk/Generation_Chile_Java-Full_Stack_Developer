# Operadores, Precedencia (BODMAS) y Funciones en Java

## 🧾 **Descripción técnica**

Este tema introduce los **operadores aritméticos**, la **precedencia de operaciones (BODMAS)** y la creación de **métodos (funciones en Java)**.

Los estudiantes comprenderán:

- Qué son los operadores aritméticos y lógicos en Java.
- Cómo Java evalúa expresiones según el orden de precedencia.
- Cómo crear y usar métodos (`static`).
- Por qué los métodos permiten escribir código más limpio y reutilizable.

---

## BODMAS ****

Es un **acrónimo que indica el orden de las operaciones matemáticas para resolver correctamente una expresión**. Las letras significan: Brackets (Paréntesis), Orders (Órdenes/potencias y raíces), Division (División), Multiplication (Multiplicación), Addition (Suma) y Subtraction (Resta). Las operaciones con la misma prioridad (División/Multiplicación y Suma/Resta) se resuelven de izquierda a derecha.

# 🔢 **1. Precedencia de Operaciones (BODMAS en Java)**

Java sigue un orden de ejecución equivalente a BODMAS:

| Prioridad | Operación |
| --- | --- |
| 1 | `()` Paréntesis |
| 2 | `**` ❌ (No existe en Java) → usar `Math.pow()` |
| 3 | `*`, `/`, `%` |
| 4 | `+`, `-` |

👉 Importante:

- Java **no tiene operador de potencia (`*`)**
- Se usa:

```java
Math.pow(2, 3); // 8.0
```

---

### 🧠 Ejemplo de precedencia:

```java
int resultado = 5 + 3 * 2;
System.out.println(resultado); // 11
```

✔ Primero multiplica → `3 * 2 = 6`

✔ Luego suma → `5 + 6 = 11`

---

### 🧠 Ejemplo con paréntesis:

```java
int resultado = (5 + 3) * 2;
System.out.println(resultado); // 16
```

---

> 💬 “El computador no piensa como tú… sigue reglas estrictas.
> 
> 
> Si no usas paréntesis, Java decide por ti.”
>

# ➕ **2. Operadores Aritméticos en Java**

| Operador | Significado | Ejemplo | Resultado |
| --- | --- | --- | --- |
| `+` | Suma | `5 + 3` | `8` |
| `-` | Resta | `10 - 2` | `8` |
| `*` | Multiplicación | `4 * 2` | `8` |
| `/` | División | `10 / 2` | `5` |
| `%` | Módulo | `10 % 3` | `1` |

---

### ⚠️ Ojo con la división en Java

```java
int resultado = 10 / 3;
System.out.println(resultado); // 3 ❌ (no 3.33)
```

✔ Porque ambos son `int`

```java
double resultado = 10.0 / 3;
System.out.println(resultado); // 3.3333 ✔
```

---

> 🧩 “El tipo de dato define el resultado, no solo la operación.”
>

# 🧠 **3. Operadores Lógicos**

| Operador | Significado | Ejemplo | Resultado |
| --- | --- | --- | --- |
| `&&` | AND | `true && false` | `false` |
| ` |  | ` | OR |
| `!` | NOT | `!true` | `false` |

---

### 🧠 Ejemplo práctico:

```java
int edad = 20;
boolean tieneEntrada = true;

if (edad >= 18 && tieneEntrada) {
    System.out.println("Puedes entrar");
}
```

# 🧱 **4. Métodos (Funciones en Java)**

> 💡 En Java no se llaman “funciones”, se llaman **métodos**
> 

---

## 🟦 **4.1 Método básico**

```java
public class Main {

    public static void saludar(String nombre) {
        System.out.println("Hola " + nombre + ", bienvenido a Java!");
    }

    public static void main(String[] args) {
        saludar("Hackerman");
    }
}
```

---

## 🟩 **4.2 Método con retorno**

```java
public class Main {

    public static int sumar(int a, int b) {
        return a + b;
    }

    public static void main(String[] args) {
        int resultado = sumar(5, 10);
        System.out.println("Resultado: " + resultado);
    }
}
```

---

### 🧠 Concepto clave:

- `return` → devuelve un valor
- `void` → no devuelve nada

---

> 💬 “Un método sin return solo ejecuta…
> 
> 
> un método con return **produce valor reutilizable**.”
>

# 🧩 **5. Ejemplo combinando TODO**

```java
public class Main {

    public static int calcular(int a, int b) {
        return (a + b) * 2;
    }

    public static void main(String[] args) {

        int resultado = calcular(5, 3);

        if (resultado > 10 && resultado < 20) {
            System.out.println("Resultado válido: " + resultado);
        } else {
            System.out.println("Resultado fuera de rango");
        }
    }
}
```

# ⚠️ **6. Errores Comunes**

| Error | Problema | Solución |
| --- | --- | --- |
| Usar `/` con enteros | pierde decimales | usar `double` |
| Olvidar `return` | no devuelve nada | agregar `return` |
| Confundir `=` con `==` | asignación vs comparación | usar `==` |
| No usar paréntesis | resultados inesperados | usar `()` |

## OperadoresDemo.java

```java
public class OperadoresDemo {

    public static void main(String[] args) {

        System.out.println("=== DEMO OPERADORES EN JAVA ===");

        int a = 10;
        int b = 3;

        // ========================
        // ➕ OPERADORES ARITMÉTICOS
        // ========================
        System.out.println("\n--- OPERADORES ARITMÉTICOS ---");

        System.out.println("a = " + a + ", b = " + b);

        System.out.println("Suma (a + b): " + (a + b));
        System.out.println("Resta (a - b): " + (a - b));
        System.out.println("Multiplicación (a * b): " + (a * b));
        System.out.println("División (a / b): " + (a / b)); // división entera
        System.out.println("Módulo (a % b): " + (a % b));

        System.out.println("👉 Ojo: int / int = división entera (sin decimales)");

        // ========================
        // 🔁 OPERADORES DE INCREMENTO
        // ========================
        System.out.println("\n--- INCREMENTO / DECREMENTO ---");

        int x = 5;

        System.out.println("Valor inicial x: " + x);
        System.out.println("x++ (post incremento): " + (x++));
        System.out.println("Después de x++: " + x);

        System.out.println("++x (pre incremento): " + (++x));
        System.out.println("Después de ++x: " + x);

        System.out.println("👉 x++ usa el valor y luego suma");
        System.out.println("👉 ++x suma primero y luego usa el valor");

        // ========================
        // ⚖️ OPERADORES RELACIONALES
        // ========================
        System.out.println("\n--- OPERADORES RELACIONALES ---");

        System.out.println("a == b: " + (a == b));
        System.out.println("a != b: " + (a != b));
        System.out.println("a > b: " + (a > b));
        System.out.println("a < b: " + (a < b));
        System.out.println("a >= b: " + (a >= b));
        System.out.println("a <= b: " + (a <= b));

        System.out.println("👉 Devuelven true o false");

        // ========================
        // 🔗 OPERADORES LÓGICOS
        // ========================
        System.out.println("\n--- OPERADORES LÓGICOS ---");

        boolean cond1 = true;
        boolean cond2 = false;

        System.out.println("cond1: " + cond1);
        System.out.println("cond2: " + cond2);

        System.out.println("AND (cond1 && cond2): " + (cond1 && cond2));
        System.out.println("OR (cond1 || cond2): " + (cond1 || cond2));
        System.out.println("NOT (!cond1): " + (!cond1));

        System.out.println("👉 AND (&&): ambas deben ser true");
        System.out.println("👉 OR (||): al menos una true");
        System.out.println("👉 NOT (!): invierte el valor");

        // ========================
        // 🧠 EJEMPLO REAL
        // ========================
        System.out.println("\n--- EJEMPLO REAL ---");

        int edad = 20;
        boolean tieneCarnet = true;

        System.out.println("Edad: " + edad);
        System.out.println("Tiene carnet: " + tieneCarnet);

        boolean puedeConducir = edad >= 18 && tieneCarnet;

        System.out.println("¿Puede conducir?: " + puedeConducir);

        System.out.println("👉 Se combinan condiciones reales");

        System.out.println("\n=== FIN DEMO ===");
    }
}
```
