## 🎯 **¿Qué es este tutorial?**

Este proyecto es un **entrenador visual de Flexbox y Grid**, diseñado especialmente para estudiantes que están aprendiendo layouts modernos en CSS.

Permite **modificar propiedades en tiempo real**, ver el resultado al instante, copiar el código generado y experimentar con la distribución de elementos.

Es el equivalente a un **laboratorio práctico**, pero accesible, interactivo y simple.

---

# 🧩 **¿Qué aprenderás con este proyecto?**

### ✔️ **Flexbox (diseño unidimensional)**

- Dirección del eje principal
- Alineación de elementos
- Distribución del espacio
- Control del wrapping
- Manejo de `gap`
- Agregar y quitar ítems dinámicamente

---

### ✔️ **CSS Grid (diseño bidimensional)**

- Configuración de columnas y filas
- Uso de `repeat`, `fr`, `auto-fit`, `minmax()`
- Alineación en dos ejes
- Distribución responsiva
- Creación de estructuras complejas
- Agregar y quitar ítems dinámicamente

---

# 📦 **Componentes del Proyecto**

Este repositorio consiste en 3 partes principales:

---

## 📄 **1. index.html**

Contiene toda la estructura del proyecto:

- Sistema de tabs (Flexbox vs Grid)
- Panel lateral con controles
- Vista previa dinámica
- Bloque de código generado automáticamente

Incluye Bootstrap + Icons para UI clara y limpia.

*(Revisar el archivo aquí → `index.html`)*

---

## 🎨 **2. styles.css**

Responsable del diseño completo:

- Colores con gradiente moderno
- Sombras
- Tarjetas
- Panel de controles
- Ítems Flex y Grid estilizados
- Caja de código tipo editor real

Este archivo convierte el laboratorio en una app visualmente profesional.

*(Revisar el archivo aquí → `styles.css`)*

---

## ⚙️ **3. app.js**

El corazón lógico del tutorial.

Controla todo:

### 🟣 Flexbox

- Actualización de propiedades
- Construcción del CSS dinámico
- Agregar/quitar ítems
- Reiniciar el estado visual

### 🔵 Grid

- Cambiar columnas y filas
- Ajustar alineamiento
- Modificar gap
- Agregar/quitar ítems
- Generación del código CSS final

Todo está organizado en funciones limpias y fácilmente extendibles.

*(Revisar el archivo aquí → `app.js`)*
