# El Modelo de Caja (Box Model)

# 🎨 **1. El Modelo de Caja (Box Model) – Explicación General**

> [!Note]
> Todo elemento en una página web es una caja.
> 
> No importa si es un `<p>`, `<h1>`, `<div>`, `<header>`, `<button>` o un `<img>`.
> 
> Todos se dibujan siguiendo el **Box Model**.

El Box Model está compuesto por:

1. **Content** → el contenido real (texto, imagen, etc.)
2. **Padding** → espacio interior
3. **Border** → borde alrededor
4. **Margin** → espacio exterior

# 🧩 **2. Propiedades del Modelo de Caja**

## **2.1. Width y Height**

Controlan el tamaño del contenido (no del padding ni del margen):

```css
.box {
  width: 250px;
  height: 120px;
}
```

👉 Mejor práctica moderna: usar **unidades fluidas** o `clamp()`.

---

## **2.2. Padding (espacio interno)**

```css
.container {
  padding: 20px;
}
```

También puede ser por lados:

```css
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;
```

O versión abreviada:

```css
padding: 10px 20px;
```

---

## **2.3. Border (borde)**

```css
.box {
  border: 2px solid #555;
}
```

---

## **2.4. Margin (espacio externo)**

```css
.box {
  margin: 30px;
}
```

---

## **2.5. box-sizing (moderno)**

Por defecto, width NO incluye padding ni border.

Para evitar confusión, se recomienda:

```css
* {
  box-sizing: border-box;
}
```

Esto cambia la forma en que se calcula el tamaño, haciéndolo más predecible.

# 📌 **3. Display – Cómo se comportan los elementos**

Los elementos HTML pueden comportarse de distintas maneras dependiendo del valor de su propiedad `display`.

---

## ✔ **3.1. Block**

- Ocupa **todo el ancho** disponible.
- Siempre inicia en **una nueva línea**.

Ejemplos: `<div>`, `<p>`, `<h1>`.

```css
.block-example {
  display: block;
}
```

---

## ✔ **3.2. Inline**

- No inicia nueva línea.
- No permite modificar height/width.

Ejemplos: `<span>`, `<a>`.

```css
.inline-example {
  display: inline;
}
```

---

## ✔ **3.3. Inline-block**

Mezcla lo mejor de ambos:

- Se comporta como línea (puede estar junto a otros elementos).
- Sí acepta width/height.

```css
.item {
  display: inline-block;
  width: 120px;
}
```

---

## ✔ **3.4. Flex (CSS moderno esencial)**

```css
.container {
  display: flex;
  gap: 10px;
  justify-content: center;
  align-items: center;
}
```

---

## ✔ **3.5. Grid (layout profesional)**

```css
.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}
```

# 📡 **4. Position – Cómo se colocan las cajas**

Controla la forma en la que un elemento se posiciona respecto al flujo del documento.

---

## **4.1. Static (por defecto)**

Todos los elementos se muestran en orden normal.

---

## **4.2. Relative**

Se mueve sin salir de su espacio original.

```css
.box {
  position: relative;
  top: 10px;
  left: 20px;
}
```

---

## **4.3. Absolute**

Se posiciona respecto al PRIMER contenedor que NO sea static.

```css
.child {
  position: absolute;
  top: 0;
  right: 0;
}
```

---

## **4.4. Fixed**

Se queda fijo en pantalla aunque scrollée.

```css
.menu {
  position: fixed;
  top: 0;
}
```

---

## **4.5. Sticky**

Se comporta como relative **hasta** que se activa con el scroll.

```css
.header {
  position: sticky;
  top: 0;
}
```

# 🎛 **5. Selectores CSS – Explicación ampliada**

---

## **5.1. Selectores básicos**

```css
h1 {}
p {}
```

---

## **5.2. Selectores por clase (recomendado)**

```css
.title { color: blue; }
```

---

## **5.3. Selectores por atributo**

```css
input[type="number"] {
  border-color: green;
}
```

---

## **5.4. Selectores avanzados modernos**

### `:is()`

```css
:is(h1, h2, h3) {
  text-transform: uppercase;
}
```

### `:where()` (especificidad 0)

Perfecto para resets.

### `:has()`

El “selector padre”, extremadamente poderoso.

```css
.card:has(.highlight) {
  border-color: orange;
}
```

# 🎨 **6. Unidades CSS modernas**

| Tipo | Ejemplo | Uso |
| --- | --- | --- |
| Fijas | `px` | Elementos rígidos |
| Relativas | `rem`, `em` | Tipografía, responsive |
| Viewport | `vw`, `vh`, `svh`, `lvh` | Layout fluido |
| Funciones modernas | `min()`, `max()`, `clamp()` | Adaptabilidad |

Ejemplo:

```css
h1 {
  font-size: clamp(2rem, 5vw, 4rem);
}

```

# 🧬 **7. Variables en CSS (Design Tokens)**

```css
:root {
  --primary: #6366f1;
  --radius: 8px;
}

```

```css
button {
  background: var(--primary);
  border-radius: var(--radius);
}

```

# ⚙️ **8. Buenas prácticas obligatorias**

- ❌ No usar estilos inline
- ❌ No usar IDs para estilado
- ✔ Usar clases semánticas
- ✔ CSS separado en archivo externo
- ✔ Usar `box-sizing: border-box`
- ✔ Reutilizar variables CSS
- ✔ Mantener el HTML limpio
