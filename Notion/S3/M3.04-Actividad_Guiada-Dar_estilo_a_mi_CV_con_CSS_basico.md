# Actividad Guiada: Dar estilo a mi CV con CSS básico

> [!NOTE]
> **Objetivo:** tomar el CV creado anteriormente solo con HTML y mejorarlo visualmente usando **CSS básico**, aplicando colores, tamaños, bordes, espaciados y organización general, sin cambiar el foco principal: entender qué hace cada regla CSS y por qué se usa.

## 🧠 Antes de empezar

En la actividad anterior, el CV estaba hecho solo con HTML.

Eso estuvo bien, porque HTML sirve para:

- dar estructura
- organizar contenido
- definir títulos, párrafos, listas, enlaces, tablas, secciones y más

Ahora vamos al siguiente paso:

- **HTML** → estructura
- **CSS** → apariencia visual

Eso significa que el contenido seguirá siendo el mismo, pero ahora se verá más ordenado, más agradable y más profesional.

---

# 📁 Archivos que deben tener

Tu proyecto ahora debe quedar así:

```markdown
mi-cv/
│── index.html
│── styles.css
│── foto.jpg   (opcional)
```

---

# 🔗 Paso 1: conectar el CSS con el HTML

Dentro del archivo `index.html`, en la etiqueta `<head>`, deben agregar esta línea:

```html
<link rel="stylesheet" href="styles.css">
```

Quedaría así:

```html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>CV de Hackerman</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
</body>
</html>
```

### ✅ ¿Qué hace esto?

Le dice al navegador:

“además del HTML, también carga este archivo CSS y úsalo para aplicar estilos”.

### ✅ ¿Por qué así?

Porque usar un archivo externo es la forma estándar y recomendada de trabajar CSS, en vez de usar estilos inline o internos

# 🪜 Tutorial guiado paso a paso

---

## 1) Dar estilo general a toda la página

En `styles.css`, escribe esto:

```css
body {
  font-family: Arial, sans-serif;
  background-color: #f4f6f8;
  color: #222;
  margin: 0;
  padding: 20px;
}
```

### ✅ ¿Qué hace cada línea?

### `font-family: Arial, sans-serif;`

Cambia la tipografía general del documento.

### `background-color: #f4f6f8;`

Le da un fondo gris muy claro a toda la página.

### `color: #222;`

Define el color base del texto.

### `margin: 0;`

Quita el margen automático que trae el navegador.

### `padding: 20px;`

Agrega espacio interior alrededor de toda la página.

### ✅ ¿Por qué usar esto?

Porque los navegadores traen estilos por defecto, y muchas veces dejan espacios que no controlamos. CSS nos permite tomar ese control

---

## 2) Hacer que el CV parezca una tarjeta principal

Si tu contenido está dentro del `<body>`, puedes envolverlo en un contenedor.

En `index.html`:

```html
<body>
  <div class="cv-container">

    <!-- todo tu CV aquí -->

  </div>
</body>
```

Ahora en `styles.css`:

```css
.cv-container {
  max-width: 900px;
  margin: 0 auto;
  background-color: white;
  padding: 30px;
  border-radius: 12px;
}
```

### ✅ ¿Qué hace esto?

### `max-width: 900px;`

Limita el ancho máximo del CV.

### `margin: 0 auto;`

Centra horizontalmente el contenedor. Esta técnica funciona muy bien cuando el elemento tiene un ancho definido o máximo ancho

### `background-color: white;`

Hace que el CV tenga fondo blanco.

### `padding: 30px;`

Da espacio interno entre el borde y el contenido.

### `border-radius: 12px;`

Redondea las esquinas.

### ✅ ¿Qué están aprendiendo aquí?

Están usando el **modelo de caja**:

- contenido
- padding
- borde
- margen

---

## 3) Dar estilo al encabezado principal

Supongamos que el HTML tiene esta parte:

```html
<header>
  <h1>Hackerman</h1>
  <p>Estudiante de Bootcamp Full Stack Java</p>
</header>
```

Ahora en CSS:

```css
header {
  text-align: center;
  border-bottom: 2px solid #dbe2ea;
  padding-bottom: 20px;
  margin-bottom: 30px;
}
```

### ✅ ¿Qué hace?

### `text-align: center;`

Centra el texto del encabezado.

### `border-bottom: 2px solid #dbe2ea;`

Agrega una línea inferior para separar visualmente el header.

### `padding-bottom: 20px;`

Agrega espacio interno antes de la línea.

### `margin-bottom: 30px;`

Deja separación entre el header y la siguiente sección.

### ✅ Aquí se ve la diferencia entre padding y margin

- **padding** = espacio interno
- **margin** = espacio externo

---

## 4) Poner el título principal en azul

Ahora sí, el ejemplo que querías.

```css
h1 {
  color: #1d4ed8;
  font-size: 36px;
  margin-bottom: 10px;
}
```

### ✅ ¿Qué hace?

### `color: #1d4ed8;`

Pinta el título principal de azul.

### `font-size: 36px;`

Hace el título más grande.

### `margin-bottom: 10px;`

Separa el título del texto que viene abajo.

### ✅ ¿Por qué este código?

Porque el `h1` es el elemento más importante del CV. Visualmente debe destacar más que el resto.

---

## 5) Mejorar el subtítulo o descripción

```css
header p {
  font-size: 18px;
  color: #555;
}
```

### ✅ ¿Qué hace?

Selecciona el párrafo que está dentro del `header`.

### `font-size: 18px;`

Hace el texto un poco más grande que un párrafo normal.

### `color: #555;`

Lo deja en un gris más suave.

### ✅ ¿Qué selector es este?

Es un **selector descendiente**, porque está apuntando a un `p` dentro de `header`

---

## 6) Dar estilo a las secciones del CV

Si tu HTML tiene:

```html
<section>
  <h2>Información de contacto</h2>
  <p>Email: hackerman@email.com</p>
</section>
```

Usa esto:

```css
section {
  margin-bottom: 25px;
}
```

### ✅ ¿Qué hace?

Separa cada sección de la siguiente.

### ✅ ¿Por qué conviene?

Porque sin espacio visual, todo se ve pegado y cuesta leer.

---

## 7) Dar estilo a los subtítulos de cada sección

```css
h2 {
  color: #0f172a;
  font-size: 24px;
  border-left: 5px solid #2563eb;
  padding-left: 10px;
  margin-bottom: 15px;
}
```

### ✅ ¿Qué hace?

### `color: #0f172a;`

Oscurece el título para que se vea fuerte.

### `font-size: 24px;`

Lo hace más grande que un texto normal, pero menor que el `h1`.

### `border-left: 5px solid #2563eb;`

Agrega una línea azul al lado izquierdo.

### `padding-left: 10px;`

Separa el texto de esa línea azul.

### `margin-bottom: 15px;`

Deja espacio antes del contenido.

### ✅ ¿Qué aprenden aquí?

Que un borde también puede ayudar a organizar visualmente un contenido, no solo decorar.

---

## 8) Mejorar párrafos y textos normales

```css
p {
  line-height: 1.6;
  margin: 8px 0;
}
```

### ✅ ¿Qué hace?

### `line-height: 1.6;`

Aumenta el espacio entre líneas.

### `margin: 8px 0;`

Agrega margen arriba y abajo.

### ✅ ¿Por qué sirve?

Porque mejora mucho la lectura. En CSS, la legibilidad también es diseño básico.

---

## 9) Dar estilo a listas de habilidades y estudios

```css
ul {
  padding-left: 20px;
}

li {
  margin-bottom: 8px;
}
```

### ✅ ¿Qué hace?

### `padding-left: 20px;`

Mueve la lista un poco hacia la derecha.

### `margin-bottom: 8px;`

Separa cada elemento de la lista.

### ✅ ¿Qué están practicando?

Otra vez el box model y los espacios internos/externos

---

## 10) Dar estilo a los enlaces

```css
a {
  color: #2563eb;
  text-decoration: none;
}

a:hover {
  text-decoration: underline;
}
```

### ✅ ¿Qué hace?

### `color: #2563eb;`

Pone los enlaces en azul.

### `text-decoration: none;`

Quita el subrayado por defecto.

### `a:hover`

Cuando pasas el mouse encima, vuelve a mostrar subrayado.

### ✅ ¿Por qué está bueno esto?

Porque enseña una primera interacción visual simple sin usar JavaScript.

---

## 11) Dar estilo a la foto si existe

Si el alumno usa:

```html
<img src="foto.jpg" alt="Foto de perfil de Hackerman">
```

Puede aplicar:

```css
img {
  width: 150px;
  border-radius: 50%;
  margin-top: 15px;
  border: 3px solid #2563eb;
}
```

### ✅ ¿Qué hace?

### `width: 150px;`

Define un tamaño fijo.

### `border-radius: 50%;`

Convierte la imagen en círculo.

### `margin-top: 15px;`

Separa la imagen del texto superior.

### `border: 3px solid #2563eb;`

Agrega un borde azul.

---

## 12) Dar estilo a la tabla de idiomas

Si tienen una tabla, pueden aplicar:

```css
table {
  width: 100%;
  border-collapse: collapse;
  margin-top: 10px;
}

th,
td {
  border: 1px solid #cbd5e1;
  padding: 10px;
  text-align: left;
}

th {
  background-color: #e2e8f0;
}
```

### ✅ ¿Qué hace?

### `width: 100%;`

La tabla ocupa todo el ancho disponible.

### `border-collapse: collapse;`

Une los bordes para que no se vean dobles.

### `padding: 10px;`

Da espacio dentro de cada celda.

### `background-color` en `th`

Diferencia visualmente los encabezados.

---

## 13) Dar estilo al pie de página

```css
footer {
  text-align: center;
  margin-top: 30px;
  padding-top: 15px;
  border-top: 1px solid #dbe2ea;
  color: #666;
  font-size: 14px;
}
```

### ✅ ¿Qué hace?

Cierra visualmente el CV con una línea superior, texto más pequeño y centrado.

# 📌 Reglas de la actividad

## Obligatorio

- usar archivo externo `styles.css`
- conectar correctamente el CSS con `<link>`
- aplicar al menos:
    - color
    - fondo
    - tipografía
    - espaciado
    - borde
    - estilos en títulos
    - estilos en enlaces
    - estilos en listas

## No permitido

- usar `style=""` dentro del HTML
- usar CSS copiado completo sin entenderlo
- borrar la estructura semántica que ya habían hecho

---

# 🌟 Libertad creativa

Los estilos sugeridos en esta guía son una **base de trabajo**.

Cada estudiante puede:

- cambiar colores
- cambiar tamaños
- cambiar bordes
- cambiar tipografías
- agregar más estilos
- modificar el diseño sugerido

siempre que mantenga:

- el HTML limpio
- el CSS en `styles.css`
- una estructura ordenada
- y decisiones coherentes

En otras palabras:

> [!NOTE]
> **si alguien quiere agregar o modificar los estilos sugeridos, es decisión propia y está permitido.**
