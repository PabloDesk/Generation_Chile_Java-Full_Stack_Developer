# Cloud Computing (SaaS, PaaS, IaaS + Cloud Economics)

## 🎯 Objetivo

<aside>

Comprender cómo funcionan los modelos de servicio en la nube y cómo impactan directamente en el desarrollo, despliegue y escalabilidad de aplicaciones modernas. 

</aside>

---

## 🚀 ¿Por qué esto es importante como developer?

- Tu código **no vive en tu computador**, vive en servidores
- Necesitas **deployar aplicaciones**
- Debes entender **costos, escalabilidad y disponibilidad**
- Vas a trabajar con plataformas como:
    - Amazon Web Services
    - Google Cloud
    - Microsoft Azure

---

## 🧠 1. ¿Qué es Cloud Computing?

### 📌 Definición simple

Uso de recursos computacionales (servidores, almacenamiento, redes) a través de internet, sin necesidad de tener infraestructura propia.

---

### ⚙️ Definición técnica

Modelo que permite acceso bajo demanda a recursos compartidos configurables (servidores, redes, almacenamiento, aplicaciones).

---

### 💻 Ejemplo real

Antes:

- Instalabas tu app en un PC o servidor físico

Ahora:

- Deploy en la nube (ej: Render, AWS, Vercel)

---

## 🧩 2. Modelos de Servicio (núcleo del cloud)

---

### 🔹 IaaS — Infrastructure as a Service

### 📌 ¿Qué es?

Te entregan infraestructura virtual (servidores, red, almacenamiento).

### ⚙️ Tú gestionas:

- Sistema operativo
- Aplicaciones
- Seguridad
- Configuración

### ❌ No gestionas:

- Hardware físico
- Data center

### 💻 Ejemplo real:

- EC2 en Amazon Web Services

---

### 🔹 PaaS — Platform as a Service

### 📌 ¿Qué es?

Te entregan una plataforma lista para ejecutar tu código.

### ⚙️ Tú gestionas:

- Tu aplicación
- Lógica de negocio

### ❌ No gestionas:

- Servidor
- Sistema operativo
- Infraestructura

### 💻 Ejemplo real:

- Render
- Heroku

---

### 🔹 SaaS — Software as a Service

### 📌 ¿Qué es?

Software listo para usar a través de internet.

### ⚙️ Tú solo:

- Usas la aplicación

### ❌ No gestionas:

- Nada técnico

### 💻 Ejemplo real:

- Google Docs
- Gmail

---

## 📊 3. Comparación clave (visión developer)

| Modelo | Nivel de control | Responsabilidad | Uso típico |
| --- | --- | --- | --- |
| IaaS | Alto | Configuración total | Backend complejo |
| PaaS | Medio | Código | Deploy rápido |
| SaaS | Bajo | Uso | Herramientas |

## 💻 5. Conexión directa con desarrollo

### 🧩 Situaciones reales:

- `npm run dev` → local (no cloud)
- Deploy → cloud
- API → vive en servidor remoto
- DB → tiene IP pública/privada

---

### ⚠️ Problemas típicos:

- “Funciona en local pero no en producción”
- Problemas de configuración
- Falta de escalabilidad
- Costos inesperados

---

## 💰 6. Cloud Economics (lo que NADIE te explica bien)

---

### 📌 Conceptos clave

| Concepto | Significado |
| --- | --- |
| CapEx | Compra de infraestructura |
| OpEx | Pago por uso (cloud) |

---

### ⚙️ Ventajas del cloud

- Escalabilidad automática
- Pago por uso
- Alta disponibilidad
- Menor inversión inicial

---

### ❗ Riesgos reales

- Costos descontrolados
- Mala configuración = gasto innecesario
- Dependencia del proveedor

---

### 🧩 Ejemplo:

## 🌍 8. Caso práctico real

### 🧪 Escenario:

> “Tu app crece rápidamente y colapsa”
> 

---

### ❓ Preguntas:

- ¿Qué modelo estás usando?
- ¿Puedes escalar fácilmente?
- ¿Tu infraestructura lo soporta?

---

### ✅ Respuesta esperada:

- IaaS → más control, más complejo
- PaaS → más rápido escalar
- SaaS → no aplica (no desarrollas)
