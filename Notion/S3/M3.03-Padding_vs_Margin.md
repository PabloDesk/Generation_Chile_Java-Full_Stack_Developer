# Padding vs Margin

# 🧩 **Infografía: Padding vs Margin (1, 2, 3 y 4 valores)**

### *Entiende cómo funcionan estos dos pilares del Box Model en sólo una página.*

---

# 🎯 **¿Qué son?**

### 🟦 **Padding**

➡ *Espacio interno*

Separación **dentro** del elemento, entre el contenido y el borde.

### 🟧 **Margin**

➡ *Espacio externo*

Separación **fuera** del elemento, entre la caja y otras cajas.

---

# 🔢 **Regla universal (aplica a ambos): 1, 2, 3 y 4 valores**

### ✔ Orden siempre igual

**Arriba → Derecha → Abajo → Izquierda**

*(como las agujas del reloj)*

---

# 📚 **1 Valor — (A)**

Aplicado a **los 4 lados por igual**

```
padding: 20px;
margin: 20px;

```

| Arriba | Derecha | Abajo | Izquierda |
| --- | --- | --- | --- |
| 20px | 20px | 20px | 20px |

---

# 📚 **2 Valores — (A B)**

A = Arriba/Abajo

B = Derecha/Izquierda

```
padding: 10px 40px;
margin: 10px 40px;

```

| Arriba | Derecha | Abajo | Izquierda |
| --- | --- | --- | --- |
| 10px | 40px | 10px | 40px |

---

# 📚 **3 Valores — (A B C)**

A = Arriba

B = Derecha/Izquierda

C = Abajo

```
padding: 10px 20px 30px;
margin: 10px 20px 30px;
```

| Arriba | Derecha | Abajo | Izquierda |
| --- | --- | --- | --- |
| 10px | 20px | 30px | 20px |

---

# 📚 **4 Valores — (A B C D)**

A = Arriba

B = Derecha

C = Abajo

D = Izquierda

```
padding: 10px 20px 30px 40px;
margin: 10px 20px 30px 40px;
```

| Arriba | Derecha | Abajo | Izquierda |
| --- | --- | --- | --- |
| 10px | 20px | 30px | 40px |

# 🧠 **Diferencia clave para recordar**

| Concepto | ¿Qué afecta? | ¿Cuándo usarlo? |
| --- | --- | --- |
| **Padding** | Interior | Para dar aire al contenido |
| **Margin** | Exterior | Para separar elementos entre sí |

---

# ⭐ Bonus: Tips profesionales

### ✔ Usa `padding` para:

- Hacer que textos respiren
- Dar espacio dentro de botones, tarjetas y secciones

### ✔ Usa `margin` para:

- Separar componentes
- Controlar distancias entre cajas

### ✔ Centering mágico:

```
margin: 0 auto;

```

*(solo funciona si hay un width definido)*
