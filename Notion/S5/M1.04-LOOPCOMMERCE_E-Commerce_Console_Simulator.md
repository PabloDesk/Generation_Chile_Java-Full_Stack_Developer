# 🎯 **Descripción General**

En esta actividad, cada equipo desarrollará una aplicación de consola llamada **LoopCommerce**, que simula las operaciones básicas de un e-commerce.

El objetivo es demostrar dominio de:

- `while`
- `do-while`
- `for`
- `foreach`
- uso de **Scanner**
- manejo de variables, operadores y control de flujo

El proyecto debe subirse a **GitHub**, con su respectivo **README**, `.gitignore` y commits con convenciones.

# 🛒 **Enunciado**

Cada grupo deberá construir un programa llamado:

```
LoopCommerce.java
```

que simule un mini e-commerce por consola.

El sistema debe incluir **5 acciones principales**:

### 1) **Ver productos disponibles**

- Los productos deben almacenarse en un **arreglo de Strings**.
- Recorrerlos usando **for-each**.
- Mostrar su número y precio.

---

### 2) **Agregar productos al carrito**

- Usar un `while` para permitir agregar varios productos hasta que el usuario ingrese “0”.
- Cada producto debe sumar un valor al subtotal.
- El subtotal debe acumularse en una variable.

---

### 3) **Ver subtotal actual**

- Mostrar el monto acumulado del carrito.

---

### 4) **Realizar checkout**

- Simular un proceso de compra en **4 pasos fijos**, usando un `for`:
    1. Validación de stock
    2. Confirmación de datos
    3. Procesamiento de pago
    4. Generación de envío

Cada paso debe imprimirse con un mensaje.

---

### 5) **Salir del sistema**

- Usar un **do-while** para que el menú vuelva a mostrarse hasta que el usuario elija “Salir”.

    ```java
    import java.util.Scanner;
    
    public class LoopCommerce {
    
        public static void main(String[] args) {
    
            Scanner scanner = new Scanner(System.in);
    
            String[] products = {
                    "Mouse Gamer",
                    "Teclado Mecánico",
                    "Audífonos RGB",
                    "Monitor 24 pulgadas",
                    "Mousepad XL"
            };
    
            double[] prices = {
                    15990,
                    34990,
                    24990,
                    129990,
                    9990
            };
    
            int option;
            double subtotal = 0;
            boolean hasProductsInCart = false;
    
            do {
    
                System.out.println("\n======================================");
                System.out.println("        LOOPCOMMERCE - MENÚ");
                System.out.println("======================================");
                System.out.println("1. Ver productos disponibles");
                System.out.println("2. Agregar productos al carrito");
                System.out.println("3. Ver subtotal actual");
                System.out.println("4. Realizar checkout");
                System.out.println("5. Salir del sistema");
                System.out.println("======================================");
                System.out.print("Seleccione una opción: ");
    
                option = scanner.nextInt();
    
                switch (option) {
    
                    case 1 -> {
                        System.out.println("\n===== PRODUCTOS DISPONIBLES =====");
    
                        int productNumber = 1;
    
                        for (String product : products) {
                            System.out.printf("%d. %s - $%.0f%n",
                                    productNumber,
                                    product,
                                    prices[productNumber - 1]);
                            productNumber++;
                        }
                    }
    
                    case 2 -> {
                        int productChoice = -1;
    
                        System.out.println("\n===== AGREGAR PRODUCTOS AL CARRITO =====");
                        System.out.println("Ingrese 0 para volver al menú");
    
                        // ESTO ES UNA NEGACION != CUALQUIER NUMERO QUE SEA DIFERENTE DE 0 NOS MANTENDRA EN EL BUCLE
                        // SI YO INGRESO 0 REGRESA AOL MENOS
    
                        // SI YO INGRESO UN 1 AL 5 POR Q MI ARREGLO ES DE 5 , ME DA UN PRODUCTO
                        while (productChoice != 0) {
    
                            System.out.println("\nProductos disponibles:");
    
                            for (int i = 0; i < products.length; i++) {
                                System.out.printf("%d. %s - $%.0f%n",
                                        (i + 1),
                                        products[i],
                                        prices[i]);
                            }
    
                            System.out.print("Seleccione producto: ");
                            productChoice = scanner.nextInt();
    
                            if (productChoice >= 1 && productChoice <= products.length) {
    
                                subtotal += prices[productChoice - 1];
                                hasProductsInCart = true;
    
                                System.out.println("Producto agregado: " + products[productChoice - 1]);
                                System.out.printf("Subtotal actual: $%.0f%n", subtotal);
    
                            } else if (productChoice == 0) {
    
                                System.out.println("Volviendo al menú...");
    
                            } else {
    
                                System.out.println("Opción inválida");
                            }
                        }
                    }
    
                    case 3 -> {
                        System.out.println("\n===== SUBTOTAL =====");
    
                        if (hasProductsInCart) {
                            System.out.printf("Subtotal actual: $%.0f%n", subtotal);
                        } else {
                            System.out.println("Carrito vacío");
                        }
                    }
    
                    case 4 -> {
    
                        System.out.println("\n===== CHECKOUT =====");
    
                        if (!hasProductsInCart) {
                            System.out.println("No hay productos en el carrito");
                            break;
                        }
    
                        for (int step = 1; step <= 4; step++) {
    
                            switch (step) {
                                case 1 -> System.out.println("Paso 1: Validación de stock");
                                case 2 -> System.out.println("Paso 2: Confirmación de datos");
                                case 3 -> System.out.println("Paso 3: Procesamiento de pago");
                                case 4 -> System.out.println("Paso 4: Generación de envío");
                            }
                        }
    
                        System.out.printf("Compra realizada con éxito. Total: $%.0f%n", subtotal);
    
                        subtotal = 0;
                        hasProductsInCart = false;
                    }
    
                    case 5 -> System.out.println("\nGracias por usar LoopCommerce");
    
                    default -> System.out.println("Opción inválida");
                }
    
            } while (option != 5);
    
            scanner.close();
        }
    }
    ```
