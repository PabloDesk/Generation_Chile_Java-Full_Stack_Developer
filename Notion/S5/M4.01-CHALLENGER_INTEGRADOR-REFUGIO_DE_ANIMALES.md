## 🎯 Contexto del problema

Un **Refugio de Animales** necesita un sistema en consola para gestionar:

- Animales rescatados
- Especies
- Adoptantes
- Estados de adopción
- Reportes generales

El sistema debe ser **simple, robusto y claro**, pensado para uso diario por voluntarios.

---

## 📌 Reglas generales del challenger

- Archivo único: `RefugioAnimales.java`
- Usar `Scanner` para interacción
- Menú principal con `do-while`
- Todas las funciones deben ser `static`
- No usar POO (todavía)
- Validar entradas
- El programa **no debe romperse**

---

## 🧩 Estructuras de datos OBLIGATORIAS

Debes usar **TODAS**:

### 1️⃣ List — Animales

```java
List<String> animales;
```

Ejemplo: `"Firulais", "Mishi", "Rocky"`

---

### 2️⃣ Map — Animal → Estado

```java
Map<String, String> estadoAnimal;
```

Ejemplo:

- Firulais → "Disponible"
- Mishi → "Adoptado"

---

### 3️⃣ Set — Especies

```java
Set<String> especies;
```

Ejemplo:

- Perro
- Gato
- Conejo

---

### 4️⃣ Map — Animal → Especie

```java
Map<String, String> animalEspecie;
```

---

### 5️⃣ Array — Contadores fijos

```java
String[] estados = {"Disponible","Adoptado"};
```

## 🧭 Menú principal (OBLIGATORIO)

```
=== REFUGIO DE ANIMALES ===
1. Registrar animal
2. Registrar especie
3. Marcar animal como adoptado
4. Mostrar animales disponibles
5. Mostrar animales adoptados
6. Mostrar reporte general
7. Salir
```

---

## 🔹 Opción 1 — Registrar animal

### Requisitos

- Pedir nombre del animal
- Pedir especie
- Validar que la especie exista
- Agregar el animal a la lista
- Guardar estado inicial: `"Disponible"`

### Validaciones

❌ No permitir animales duplicados

❌ No permitir especies inexistentes

---

## 🔹 Opción 2 — Registrar especie

### Requisitos

- Pedir nombre de la especie
- Guardarla en el `Set`
- Evitar duplicados automáticamente

---

## 🔹 Opción 3 — Marcar animal como adoptado

### Requisitos

- Mostrar lista de animales disponibles
- Permitir seleccionar uno
- Cambiar su estado a `"Adoptado"`

---

## 🔹 Opción 4 — Mostrar animales disponibles

### Requisitos

- Mostrar solo animales con estado `"Disponible"`
- Usar `for` o `Stream` (bonus)

---

## 🔹 Opción 5 — Mostrar animales adoptados

### Requisitos

- Mostrar solo animales con estado `"Adoptado"`

---

## 🔹 Opción 6 — Reporte general

### Debe mostrar:

- Total de animales
- Total disponibles
- Total adoptados
- Listado con formato tabla:

```
Nombre | Especie | Estado
```

---

## 🧠 Bonus opcional (STREAM)

Si ya se sienten cómodos, pueden usar Stream para:

- Contar animales disponibles
- Filtrar animales adoptados
- Mostrar reportes

Ejemplo (opcional):

```java
estadoAnimal.values().stream()
    .filter(e -> e.equals("Disponible"))
    .count();
```
