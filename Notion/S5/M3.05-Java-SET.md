# Java - SET

## 🎯 **Objetivo de esta página**

Al finalizar esta sección, el estudiante será capaz de:

- Entender qué es un `Set` en Java
- Comprender por qué **NO permite duplicados**
- Diferenciar los tipos de Set más comunes
- Usar `HashSet` correctamente
- Recorrer un Set
- Evitar errores comunes
- Aplicar buenas y malas prácticas
- Saber cuándo usar **Set vs List**

---

## 🧠 **1. ¿Qué es un Set en Java?**

Un **Set** es una colección que:

- NO permite elementos duplicados
- No garantiza orden (depende de la implementación)
- Almacena valores únicos

Ejemplo conceptual:

> Un Set es como una lista de asistencia:
> 
> 
> una persona puede estar **una sola vez**.
> 

---

## ❓ ¿Por qué existe Set?

Porque validar duplicados manualmente es:

❌ engorroso

❌ propenso a errores

❌ poco legible

Set **elimina ese problema desde la estructura de datos**.

---

## 🧩 **2. Jerarquía básica de Set**

```
Set → HashSet
```

(Otras implementaciones existen, pero empezamos con `HashSet`.)

📌 **Regla:** programar contra `Set`, no contra `HashSet`.

---

## ✍️ **3. Declaración de un Set**

```java
Set<String> correos = new HashSet<>();
```

✔ Genérico (`<String>`)

✔ Dinámico

✔ Sin duplicados

---

## 🧱 **4. Agregar elementos**

```java
correos.add("a@mail.com");
correos.add("b@mail.com");
correos.add("a@mail.com"); // duplicado
```

Resultado:

```
[a@mail.com, b@mail.com]
```

📌 El duplicado **no se agrega**, no da error.

---

## 🔎 **5. Verificar existencia**

```java
boolean existe = correos.contains("a@mail.com");
```

✔ Muy útil para validaciones

---

## 🗑️ **6. Eliminar elementos**

```java
correos.remove("b@mail.com");
```

---

## 📏 **7. Tamaño del Set**

```java
int total = correos.size();
```

---

## 🔁 **8. Recorrer un Set**

### 🔹 Con `foreach` (recomendado)

```java
for (String correo : correos) {
    System.out.println(correo);
}
```

📌 No hay índices.

---

### 🔹 Con `Iterator` (avanzado, opcional)

```java
Iterator<String> it = correos.iterator();
while (it.hasNext()) {
    System.out.println(it.next());
}
```

---

## ⚠️ **9. Errores Comunes con Set**

### ❌ Esperar orden

```java
System.out.println(correos);
```

❌ El orden puede cambiar.

---

### ❌ Intentar acceder por índice

```java
correos.get(0); // ❌ no existe
```

---

### ❌ Usar Set cuando el orden importa

Ejemplo incorrecto:

- ranking
- historial
- secuencia de pasos

---

## 🧼 **10. Buenas Prácticas con Set**

✔ Usar Set cuando **NO deben existir duplicados**

✔ Usar `contains()` para validaciones

✔ Preferir `HashSet` para uso general

✔ Usar Set para unicidad, no para orden

---

## ❌ **11. Malas Prácticas**

❌ Usar Set como reemplazo de List

❌ Asumir orden

❌ Forzar conversiones innecesarias

❌ Usar Set solo “porque evita duplicados” sin entender el contexto

---

## 🔄 **12. Comparación: List vs Set**

| Característica | List | Set |
| --- | --- | --- |
| Permite duplicados | ✔ | ❌ |
| Mantiene orden | ✔ | ❌ (depende) |
| Acceso por índice | ✔ | ❌ |
| Uso principal | Secuencias | Unicidad |

---

## 🧠 **13. Ejemplo aplicado (caso real)**

### Correos únicos en un sistema

```java
Set<String> correos = new HashSet<>();

correos.add("juan@mail.com");
correos.add("ana@mail.com");
correos.add("juan@mail.com"); // ignorado
```

👉 No necesitas validar duplicados manualmente.

## 💖 Reflexión 🎓

> Si un dato no puede repetirse,
> 
> **Set es la respuesta**.

---

SetExample.java

```java
import java.util.HashSet;
import java.util.Set;

public class SetExample {

    public static void main(String[] args) {
        Set<String> correos = new HashSet<>();

        // SIN DUPLICADOS
        correos.add("juan@mail.cl");
        correos.add("diego@mail.cl");
        correos.add("juan@mail.cl"); // DUPLICADO

        System.out.println("= SET =");

        for(String c: correos){
            System.out.println(c);
        }

        System.out.println("Total :" + correos.size());
    }
}

```
