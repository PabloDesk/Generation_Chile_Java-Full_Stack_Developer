## 🧠 **1. ¿Qué es Stream en Java?**

Un **Stream** es una **secuencia de datos** que se procesa paso a paso.

📌 Importante:

- **NO almacena datos**
- **NO reemplaza List, Set o Map**
- Se usa para **procesar** colecciones

> Un Stream es como una línea de producción:
> 
> 
> los datos entran, se transforman, se filtran y salen.
> 

---

## ❓ ¿Por qué existe Stream?

Antes de Java 8, todo se hacía con loops:

```java
for (int n : numeros) {
if (n >10) {
        System.out.println(n);
    }
}

```

Funciona, pero:

- es más largo
- mezcla lógica y control
- cuesta leerlo rápido

Stream nace para:

✔ escribir código más expresivo

✔ separar el **qué** del **cómo**

✔ facilitar operaciones comunes

---

## 🧩 **2. Colección vs Stream (concepto clave)**

| Colección | Stream |
| --- | --- |
| Almacena datos | Procesa datos |
| Tiene estado | No guarda estado |
| Reutilizable | Se consume una vez |
| `add()`, `remove()` | `filter()`, `map()` |

📌 **Regla de oro**

> Primero guardas datos en una colección,
> 
> 
> luego los procesas con Stream.
> 

---

## ✍️ **3. Cómo crear un Stream**

### Desde una List

```java
List<String> nombres = List.of("Ana","Juan","Pedro");

nombres.stream();

```

---

### Desde un Set

```java
set.stream();

```

---

### Desde un Map

```java
map.entrySet().stream();

```

---

### Desde un Array

```java
Arrays.stream(numeros);

```

---

## 🔧 **4. Operaciones principales de Stream**

### 🔹 `forEach` (acción final)

```java
nombres.stream()
       .forEach(System.out::println);

```

✔ Similar a `foreach`

✔ Solo para mostrar o ejecutar acciones

---

### 🔹 `filter` (filtrar datos)

```java
nombres.stream()
       .filter(n -> n.length() >4)
       .forEach(System.out::println);
```

✔ Devuelve solo los que cumplen condición

---

### 🔹 `map` (transformar datos)

```java
nombres.stream()
       .map(String::toUpperCase)
       .forEach(System.out::println);
```

✔ Transforma cada elemento

---

### 🔹 `count`

```java
long total= nombres.stream().count();
```

---

## 🧱 **5. Flujo típico de un Stream**

```java
coleccion.stream()
         .filter(...)
         .map(...)
         .forEach(...);
```

📌 Se lee **de arriba hacia abajo**

📌 Como una frase

---

## ⚠️ **6. Errores Comunes con Stream**

### ❌ Pensar que modifica la colección original

```java
nombres.stream().filter(...);
```

❌ No cambia `nombres`

✔ Para modificar, necesitas asignar a otra colección.

---

### ❌ Reutilizar un Stream

```java
Stream<String> s = nombres.stream();
s.forEach(...);
s.forEach(...);// ❌ error
```

---

### ❌ Usar Stream para todo

```java
list.stream().forEach(...);// innecesario
```

✔ A veces un `foreach` normal es mejor.

---

## 🧼 **7. Buenas Prácticas con Stream**

✔ Usar Stream para **leer y procesar**

✔ Mantener streams cortos y legibles

✔ Priorizar claridad sobre complejidad

✔ Usar nombres claros en lambdas

✔ Leer streams como una frase

---

## ❌ **8. Malas Prácticas**

❌ Streams largos e ilegibles

❌ Anidar streams complejos

❌ Reemplazar loops simples sin razón

❌ Usar streams sin entender qué hacen

---

## 🔄 **9. Comparación: Loop vs Stream**

| Aspecto | Loop | Stream |
| --- | --- | --- |
| Control | Total | Abstracto |
| Verbosidad | Alta | Baja |
| Lectura | Paso a paso | Declarativa |
| Aprendizaje | Fácil | Progresivo |

👉 **No compiten, se complementan.**

```java
import java.util.List;

public class StreamExample {

    public static void main(String[] args) {
        //FILTROS
        //FOREACH
        //STREAM Y PROCESAMIENTOS

                400000,
                500000,
                700000,

        );

                .filter(s -> s > 500000)
                .forEach(System.out::println);
    }
}
```
