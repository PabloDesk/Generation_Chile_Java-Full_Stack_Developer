# Java - MAP (HashMap)

## 🎯 **Objetivo de esta página**

Al finalizar esta sección, el estudiante será capaz de:

- Entender qué es un `Map` en Java
- Comprender el concepto **clave → valor**
- Usar `HashMap` correctamente
- Agregar, obtener y eliminar datos
- Recorrer un `Map`
- Evitar errores comunes
- Saber cuándo usar **Map vs List vs Set**
- Aplicar buenas y malas prácticas

---

## 🧠 **1. ¿Qué es un Map en Java?**

Un **Map** es una colección que almacena datos en pares:

```
clave → valor
```

Ejemplo conceptual:

> Un Map es como una agenda:
> 
- buscas por nombre → obtienes un teléfono
- buscas por RUT → obtienes un trabajador

---

## ❓ ¿Por qué existe Map?

Porque hay problemas que **NO se resuelven bien** con listas o sets:

❌ Buscar por índice

❌ Recorrer todo para encontrar algo

❌ Validaciones manuales

Map permite:

✔ búsquedas rápidas

✔ relaciones claras

✔ código más expresivo

---

## 🧩 **2. Jerarquía básica de Map**

```
Map → HashMap
```

📌 Igual que antes:

- `Map` → interfaz
- `HashMap` → implementación

👉 **Programamos contra `Map`, no contra `HashMap`.**

---

## ✍️ **3. Declaración de un Map**

```java
Map<String, Integer> sueldos = new HashMap<>();
```

- `String` → clave
- `Integer` → valor

---

## 🧱 **4. Agregar elementos (put)**

```java
sueldos.put("Juan", 500000);
sueldos.put("Ana", 650000);
```

📌 Si la clave ya existe, el valor se reemplaza.

---

## 🔎 **5. Obtener un valor (get)**

```java
int sueldo = sueldos.get("Juan");
```

⚠️ Si la clave no existe, retorna `null`.

✔ Buena práctica:

```java
if (sueldos.containsKey("Juan")) {
    System.out.println(sueldos.get("Juan"));
}
```

---

## 🗑️ **6. Eliminar elementos**

```java
sueldos.remove("Ana");
```

---

## 📏 **7. Tamaño del Map**

```java
int total = sueldos.size();
```

---

## 🔁 **8. Recorrer un Map**

### 🔹 Recorrer claves

```java
for (String clave : sueldos.keySet()) {
    System.out.println(clave);
}
```

---

### 🔹 Recorrer valores

```java
for (int valor : sueldos.values()) {
    System.out.println(valor);
}
```

---

### 🔹 Recorrer clave y valor (recomendado)

```java
for (Map.Entry<String, Integer> entry : sueldos.entrySet()) {
    System.out.println(entry.getKey() + " → " + entry.getValue());
}
```

---

## ⚠️ **9. Errores Comunes con Map**

### ❌ Esperar orden

```java
System.out.println(sueldos);
```

❌ `HashMap` no garantiza orden.

---

### ❌ Usar índices

```java
sueldos.get(0); // ❌ no existe
```

---

### ❌ No validar null

```java
int sueldo = sueldos.get("Pedro"); // ❌ posible NullPointer
```

---

## 🧼 **10. Buenas Prácticas con Map**

✔ Usar claves únicas y claras

✔ Validar con `containsKey()`

✔ Usar `entrySet()` para recorrer

✔ Usar Map cuando hay relación directa

✔ Mantener claves inmutables

---

## ❌ **11. Malas Prácticas**

❌ Usar Map cuando solo necesitas una lista

❌ Usar claves complejas sin razón

❌ Asumir orden en `HashMap`

❌ Usar Map solo “porque es más potente”

---

## 🔄 **12. Comparación: List vs Set vs Map**

| Característica | List | Set | Map |
| --- | --- | --- | --- |
| Duplicados | ✔ | ❌ | Clave ❌ |
| Orden | ✔ | ❌ | ❌ |
| Acceso por índice | ✔ | ❌ | ❌ |
| Clave → valor | ❌ | ❌ | ✔ |
| Uso típico | Secuencias | Unicidad | Relación |

---

## 🧠 **13. Ejemplo aplicado (Payroll)**

### Antes (List):

```java
List<String> nombres;
List<Integer> sueldos;
```

❌ Riesgo de desalinear datos

---

### Después (Map):

```java
Map<String, Integer> sueldos = new HashMap<>();
sueldos.put("Juan", 500000);
```

✔ Relación clara

✔ Búsqueda directa

---


MapExample.java

```java
import java.util.HashMap;
import java.util.Map;

public class MapExample {

    public static void main(String[] args) {

        // CLAVE -> VALOR
        // PUT - GET
        // RECORRER

        Map<String, Integer > sueldos = new HashMap<>();

        //PUT PARA AGREGAR
        sueldos.put("Ana", 500000);
        sueldos.put("Juan", 650000);
        sueldos.put("Pedro", 700000); // DUPLICADO, SE IGNORA - POR QUE SE SOBREESCRIBE CONSERVARNDOSE EL ULTIMO

        System.out.println(" = MAP = ");

        for(Map.Entry<String, Integer> entry : sueldos.entrySet()){
            System.out.println(entry.getKey() + " -> " + entry.getValue());
        }

        System.out.println("Sueldo Juan: " + sueldos.get("Pedro"));

    }
}
```
