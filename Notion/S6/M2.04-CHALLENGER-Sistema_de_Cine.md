# 🎬 CHALLENGER: Sistema de Cine

Este desafío tiene como objetivo aplicar los conceptos fundamentales de **Programación Orientada a Objetos (POO)** en Java, utilizando una **estructura de paquetes clara**, **herencia**, **polimorfismo**, **encapsulación**, y **colecciones**, simulando un sistema básico de cine en **modo cliente**.

<aside>

⚠️ **Importante:**
Este ejercicio es **solo el enunciado**.

El estudiante debe **diseñar y programar toda la solución**.

</aside>

---

## 🎯 Objetivo del Challenger

Construir un sistema por consola que permita:

- Crear clientes
- Registrar películas
- Crear funciones de cine
- Comprar entradas
- Mostrar información usando POO

---

## 🧠 Contenidos evaluados

✔ Clases y objetos

✔ Encapsulación

✔ Herencia

✔ Polimorfismo

✔ Colecciones (`List`)

✔ Condicionales y bucles

✔ Menú por consola

✔ Scanner

✔ Estructura por paquetes

---

## 👣 Paso 1: Crear el proyecto

📁 **Nombre sugerido:** `CineApp`

---

## 👣 Paso 2: Crear la estructura de paquetes

```
src/
├── app/          → clase principal con `main`
├── model/        → clases del dominio
├── service/      → lógica del sistema
└── util/         → utilidades (Scanner)

```

---

## 👣 Paso 3: Crear la clase base `Persona`

📄 `model/Persona.java`

### Requisitos:

- Debe representar una persona genérica.
- Debe tener:
    - atributo `nombre`
    - constructor
    - getter
- Debe ser pensada como **clase base** para otros tipos de personas.

---

## 👣 Paso 4: Crear la clase `Cliente` (herencia)

📄 `model/Cliente.java`

### Requisitos:

- Debe heredar de `Persona`.
- Debe permitir asociar **entradas compradas**.
- Usar una colección (`List`) para guardar las entradas.

---

## 👣 Paso 5: Crear la clase `Pelicula`

📄 `model/Pelicula.java`

### Requisitos:

- Atributos sugeridos:
    - título
    - duración (minutos)
- Constructor y getters.
- Método para mostrar información de la película.

---

## 👣 Paso 6: Crear la clase `Funcion`

📄 `model/Funcion.java`

### Requisitos:

- Representa una función de cine.
- Debe tener:
    - una película
    - horario
    - capacidad de la sala
- Debe llevar el control de:
    - asientos disponibles
    - entradas vendidas

---

## 👣 Paso 7: Crear la clase `Entrada`

📄 `model/Entrada.java`

### Requisitos:

- Debe asociar:
    - cliente
    - función
    - número de asiento
- Debe tener un método que muestre el resumen de la entrada.

---

## 👣 Paso 8: Crear el servicio principal del sistema

📄 `service/CineService.java`

### Requisitos:

- Debe contener:
    - lista de clientes
    - lista de funciones
- Debe mostrar un **menú por consola** con opciones como:

```
1) Crear cliente
2) Ver cartelera
3) Comprar entrada
4) Ver entradasdel cliente
0) Salir

```

- Debe usar bucles (`while`) y condicionales (`switch`).

---

## 👣 Paso 9: Clase principal

📄 `app/Main.java`

### Requisitos:

- Debe iniciar el sistema.
- Debe crear una instancia del servicio principal.
- No debe contener lógica de negocio.

---

## 👣 Paso 10: Reglas del sistema

- No se puede vender una entrada si no hay asientos disponibles.
- Un asiento no puede venderse dos veces.
- El sistema debe validar entradas incorrectas del usuario.
- Usar `try/catch` para manejar errores de entrada.

---

## 🧠 Requisitos técnicos obligatorios

✔ Uso de al menos una clase padre

✔ Uso de herencia (`extends`)

✔ Uso de polimorfismo (listas del tipo padre)

✔ Uso de colecciones

✔ Código separado por paquetes

✔ Métodos bien nombrados

✔ Uso correcto de `public`, `private`, `protected`
