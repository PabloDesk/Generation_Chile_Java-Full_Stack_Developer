# Java - Abstracción

## 🎯 Objetivo de esta subpágina

Entender qué es la **abstracción**, cuándo usarla y **por qué algunas clases no deberían poder instanciarse directamente**.

Aquí aprenderemos a:

- Crear clases abstractas
- Definir métodos abstractos
- Forzar a las clases hijas a implementar comportamiento
- Preparar el camino para interfaces

---

## 🧠 ¿Qué es la Abstracción?

La **abstracción** consiste en:

> Definir QUÉ debe hacer un objeto, sin decir CÓMO lo hace.
> 

Es decir:

- Nos quedamos con **la idea general**
- Dejamos los detalles a las clases hijas

---

## 🧩 Idea clave (frase para clase)

> No todos los conceptos deberían existir como objetos reales.
> 

Ejemplo:

- Un **Guerrero** existe
- Un **Mago** existe
- Pero un **Personaje genérico**… no

👉 `Personaje` es solo una **idea base**.

---

## 🔄 Recordemos el ejemplo anterior (sin abstracción)

Antes teníamos esto:

```java
class Personaje {

    protected String nombre;
    protected int vida;

    void atacar() {
        System.out.println(nombre + " ataca de forma básica");
    }
}

```

⚠️ Problema:

- Podemos hacer esto:

```java
Personaje p = new Personaje("X", 100);

```

❌ ¿Qué tipo de personaje es?

❌ ¿Cómo ataca realmente?

---

## 🧠 Solución: Clases Abstractas

En Java, una **clase abstracta**:

- **NO puede instanciarse**
- Sirve como **base para otras clases**
- Puede tener:
    - métodos normales
    - métodos abstractos (sin implementación)

Se declara con la palabra clave `abstract`.

---

## 🧱 Clase abstracta: `Personaje`

```java
abstract class Personaje {

    protected String nombre;
    protected int vida;

    Personaje(String nombre, int vida) {
        this.nombre = nombre;
        this.vida = vida;
    }

    // Método abstracto (sin implementación)
    abstract void atacar();

    // Método normal (compartido)
    void mostrarEstado() {
        System.out.println(nombre + " | Vida: " + vida);
    }
}

```

📌 **Clave**:

- `atacar()` **NO tiene cuerpo**
- Obliga a las clases hijas a definirlo

---

## ❌ Lo que ya NO se puede hacer

```java
Personaje p = new Personaje("X", 100);

```

❌ Error de compilación

👉 **Una clase abstracta no se puede instanciar**

---

## 🗡️ Clases hijas IMPLEMENTAN el comportamiento

### `Guerrero`

```java
class Guerrero extends Personaje {

    Guerrero(String nombre, int vida) {
        super(nombre, vida);
    }

    @Override
    void atacar() {
        System.out.println(nombre + " ataca con su espada ⚔️");
    }
}

```

---

### `Mago`

```java
class Mago extends Personaje {

    Mago(String nombre, int vida) {
        super(nombre, vida);
    }

    @Override
    void atacar() {
        System.out.println(nombre + " lanza un hechizo ✨");
    }
}

```

📌 **Obligación**:

- Si no implementan `atacar()`
- El código **no compila**

---

## 🔁 Abstracción + Polimorfismo (combinación poderosa)

```java
List<Personaje> equipo = new ArrayList<>();

equipo.add(new Guerrero("Thor", 100));
equipo.add(new Mago("Merlín", 80));

for (Personaje p : equipo) {
    p.mostrarEstado();
    p.atacar();
}

```

✔ No sabemos qué tipo concreto es

✔ No nos importa

✔ Cada uno se comporta como corresponde

---

## 🧠 Diferencia clave: Herencia vs Abstracción

| Concepto | Qué hace |
| --- | --- |
| Herencia | Reutiliza código |
| Abstracción | Define contratos de comportamiento |
| Polimorfismo | Permite múltiples comportamientos |

👉 **Las tres trabajan juntas.**

---

## 🧩 ¿Cuándo usar abstracción?

Usa una clase abstracta cuando:

- La clase **no tiene sentido por sí sola**
- Quieres forzar a las hijas a implementar métodos
- Compartes lógica común + reglas base

Gato.java
```java
package abstraccion;

public class Gato extends Mascota {

    boolean esIndoor;

    public Gato(String nombre, int edad, boolean esIndoor) {
        super(nombre, edad);
        this.esIndoor = esIndoor;
    }

    // Gato tiene su propia versión de hacerSonido()
    @Override
    public void hacerSonido() {
        System.out.println(nombre + " maulla: ¡Miau!");
    }

    // Gato tiene su propia versión de describirse()
    @Override
    public void describirse() {
        String tipo = esIndoor ? "indoor" : "outdoor";
        System.out.println("Soy un gato " + tipo + ".");
    }
}
```

---

Main.java
```java
package abstraccion;

public class Main {
    public static void main(String[] args) {

        // ERROR: no se puede instanciar una clase abstracta
        // Mascota m = new Mascota("X", 1); ← esto NO compila

        // Correcto: instanciamos las subclases concretas
        Mascota perro = new Perro("Rex", 5, "Labrador");
        Mascota gato  = new Gato("Luna", 3, true);
        
        // presentarse() es concreto: heredado directamente del padre
        perro.presentarse(); // → Soy Rex, tengo 5 años.
        gato.presentarse();  // → Soy Luna, tengo 3 años.

        // hacerSonido() y describirse() fueron IMPLEMENTADOS por cada hijo
        perro.hacerSonido(); // → Rex ladra: ¡Guau! ¡Guau!
        gato.hacerSonido();  // → Luna maulla: ¡Miau!

        perro.describirse(); // → Soy un perro de raza Labrador.
        gato.describirse();  // → Soy un gato indoor.
    }
}
```

Mascota.java
```java
package abstraccion;

// "abstract" significa que esta clase NO se puede instanciar directamente.
// Nadie puede hacer: new Mascota() ← esto daría error de compilación.
// Su propósito es ser una PLANTILLA obligatoria para sus subclases.
public abstract class Mascota {

    // Atributos comunes a toda mascota
    protected String nombre;
    protected int    edad;

    // Constructor de la clase abstracta
    public Mascota(String nombre, int edad) {
        this.nombre = nombre;
        this.edad   = edad;
    }

    // Método CONCRETO: ya tiene implementación, los hijos lo heredan tal cual
    public void presentarse() {
        System.out.println("Soy " + nombre + ", tengo " + edad + " años.");
    }

    // Método ABSTRACTO: NO tiene cuerpo ({}).
    // Cada subclase ESTÁ OBLIGADA a implementarlo con su propia lógica.
    // Si una subclase no lo implementa, Java lanza error de compilación.
    public abstract void hacerSonido();
    public abstract void describirse();
}
```

Perro.java
```java
package abstraccion;

// Perro extiende Mascota y DEBE implementar hacerSonido() y describirse()
// Si falta alguno, el programa NO compila.
public class Perro extends Mascota {

    String raza;

    public Perro(String nombre, int edad, String raza) {
        super(nombre, edad);
        this.raza = raza;
    }

    // Implementación OBLIGATORIA del método abstracto hacerSonido()
    @Override
    public void hacerSonido() {
        System.out.println(nombre + " ladra: ¡Guau! ¡Guau!");
    }

    // Implementación OBLIGATORIA del método abstracto describirse()
    @Override
    public void describirse() {
        System.out.println("Soy un perro de raza " + raza + ".");
    }
}
```
